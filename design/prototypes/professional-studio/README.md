# 专业合议工作室 · 视觉方向 C

这是“民间借贷案件编译器 / 证据驱动诉讼工作台”的两张桌面端高保真静态原型：

- `case-overview.html`：案件总览。把“现在由谁决定什么”放在首位，并以阶段、影响范围、交接与来源支撑该决定。
- `evidence-workbench.html`：证据工作台。将文件/页级处置、原始页、候选抽取与合议处置并置，保留原件与派生件的边界。

## 设计假设与取舍

方向 C 的核心不是“更多协作消息”，而是让承办、协办、助理、复核人在同一案件中交接可追溯的决定。

1. **主构图是合议记录，而不是看板。** 使用横向案件阶段、单一“下一项律师决定”、角色责任和审计线索；没有任务卡片海洋或聊天窗。
2. **正文阅读与证据核验优先。** 以纸本底色、深墨线、宋体式标题和高密度表格组织信息。页面把证据来源、候选与正式结论保持分离。
3. **状态语义不得混用。** 绿色仅表示人工已确认/已完成；赭色表示待律师决定；红色只用于证据红框和风险文本，并通过文字说明防止误读。
4. **原件和派生件明显不同。** 原始文件使用“原件 · 只读”，派生件以蓝灰标记；重复页处置的说明明确“只影响派生选页，不删除原页”。
5. **字体和色彩遵循中文桌面工作台。** 使用系统可用的中文衬线/无衬线组合，不依赖外部网络字体。视觉目标是冷静、耐读、具有律所工作交接感，而不是政府门户或通用 SaaS。

## 数据与边界

页面中的人员、案号、文件名、金额、交易号、时间、来源坐标和文书内容均为**严格合成数据**。它们不代表真实案件、个人、微信记录、法院文件、法律意见或可提交材料。

这是视觉原型：按钮、审批、哈希、OCR、页码、审计、权限、期限和金额均未连接真实服务，不能用于真实案件处理。

## 查看方式

直接在桌面浏览器打开任一 HTML 文件即可：

- [案件总览](case-overview.html)
- [证据工作台](evidence-workbench.html)

两页相互链接，推荐在 1440px 宽度查看；样式同时为 1280px 桌面宽度作了压缩处理。

当前执行环境禁止浏览器访问本地 `file://` 路径，因此已完成静态结构与内容检查；在可访问本地文件的浏览器中仍需补做 1440px 与 1280px 的肉眼截图复核。
