# 现代案卷室（方向 A）

这是“案卷工作台”第一轮视觉探索中的方向 A：现代案卷室。它是离线、静态、桌面端 HTML 原型，不是可办案系统。

## 包含内容

- **案件总览**：期限候选、下一项律师决定、流程状态、材料健康、带币种和来源的核心数字、最近审计变化；
- **证据工作台**：文件/页面列表、原件页预览、OCR/来源/交易候选、精确重复与相似非重复的处置边界、派生件前置条件；
- 两个屏幕由左侧导航和“查看来源页”按钮切换；页码与“模拟审计决定”用于检验静态交互层级。

## 设计假设与取舍

1. **核心隐喻是“正在被审阅的案卷”，不是“古风卷宗”。** 暖灰纸张、宋体标题、硬边界与少量朱红标记带来阅读节奏；不使用仿古纹样、印章、繁复装饰或政府门户式大标题。
2. **朱红仅表示关键证据标记、待处置风险或阻断，不表示成功。** 律师批准使用深绿；候选使用赭黄；这些状态始终附带中文文字。
3. **不做聊天主界面。** 系统提案只作为右侧上下文，其内容清楚标为“非结论”，并始终显示来源和不确定性。
4. **原件与派生件明确分开。** 原件有独立标识和哈希；“删除无关页面”被表达为派生件范围，不会覆盖原件。相似页面被保留在待复核队列，不能被精确重复处置静默排除。
5. **案件数据全部严格合成。** 姓名使用“原告甲/被告乙”，支付账户、案号、法院、交易号、金额、日期、哈希片段、文件名和审计角色均仅用于演示，不来自真实材料。

## 视觉系统

| 层级 | 设计选择 | 目的 |
|---|---|---|
| 画面 | 暖灰纸张、低饱和墨色、硬分隔线 | 让高密度案卷内容长时间阅读仍稳定 |
| 标题 | 宋体中文标题 + 无衬线正文 | 将“结论/决策”与“操作/来源”区分开 |
| 关键决定 | 大幅无圆角审阅页 | 优先呈现一项律师需要决定的事 |
| 数据 | 台账式行列而非同质卡片 | 保持数字、币种、来源的可核对性 |
| 证据 | 灰底阅读器 + 白色原始页 + 朱红定位框 | 区分查看原件、标出关键记录与生成派生件 |

## 边界

- 原型不计算利息、不提出法律结论、不进行真实审批、不生成或导出 PDF；
- 所有按钮仅切换静态屏幕或模拟 UI 状态；
- 以 1440px 桌面工作区为基准，CSS 在 1280px 保持关键内容可见；移动端不在 v1 范围。

## 本地查看

直接在浏览器打开 `index.html`。无需网络、账户或外部资源。
