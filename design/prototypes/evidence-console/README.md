# 视觉方向 B：证据控制台

这是“民间借贷案件编译器 / 证据驱动诉讼工作台”的第二个视觉方向。它是**静态、严格合成数据**的桌面 HTML 原型，不连接数据库、模型、OCR 或真实文件，也不能生成任何可提交法院的材料。

## 打开方式

- `index.html`：案件总览
- `evidence-workbench.html`：证据工作台

二者可直接在浏览器中打开；页面内的主要导航链接可在两个屏幕之间跳转。设计基准为 1440px 桌面宽度，并保留 1280px 最小可用宽度。

## 设计假设

这个方向假设用户的核心焦虑不是“缺少 AI 摘要”，而是无法判断材料、金额、候选结论与律师决定之间的可追溯关系。因此布局采用连续的审查台而非卡片式仪表盘：

- 案件总览只放大一项“下一项律师决定”，并显示其来源和下游影响；
- 证据工作台固定为“原件/页面清单 — 原始页预览 — 提取与处置”三栏；
- 页面处置、重复判断、OCR 坐标与派生件预览并列，让律师不用离开证据上下文；
- “原件”与“派生件”使用不同文案和位置，界面不出现“删除无关页”的误导动作；
- 交易金额、日期、币种和状态均以字段方式呈现，不用装饰性图表或无依据指标。

## 视觉取舍

色彩遵守领域语义而非装饰：

| 语义 | 使用方式 |
|---|---|
| 深墨 / 暖白 | 导航与长时间阅读面的主基调，降低高压感 |
| 蓝色 | 来源、候选关联和当前证据工作上下文 |
| 绿色 | 仅用于人工已批准 / 哈希一致等人工确认状态 |
| 琥珀色 | 待律师决定、疑似重复、结果失效等需要注意但非“证据红框”的问题 |
| 红色 | 仅用于页面上的证据坐标红框；不用于一般风险告警 |

排版使用宋体风格 display（中文长文、案卷感）配合无衬线正文和等宽字段值（数据精度、稳定定位）。不使用紫色渐变、聊天主界面、emoji、装饰性统计图、伪造图标或同质圆角卡片。

## 真实数据边界

页面中所有姓名、案号、金额、交易号、文件名、日期、审计事件及 OCR 内容均为合成测试数据。任何真实客户材料、身份信息、法院文件、电话、账户、诉讼策略或密钥均不应放入本目录或版本库。

## 尚未验证的风险

- 这是一份视觉方向样稿，尚未经过律师可用性测试，不能声称已获律师接受；
- 红框的视觉语义已与风险状态区分，但真实 PDF 缩放、旋转、OCR 坐标和多分辨率对齐仍须由后续证据 Worker 进行确定性验证；
- 当前页级“精确重复 / 相似但不同”的分类只是界面状态样例，真正判断必须保留算法版本、输入哈希、阈值和律师处置理由；
- 高风险审批、权限拒绝、失效传播和锁定提交版在后续可点击原型与工程实现中必须执行代码状态机，不应由该静态画面替代。
