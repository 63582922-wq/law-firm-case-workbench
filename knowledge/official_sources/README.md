# 官方法源发现登记

这里保存的是公开官方来源的**发现清单**，不是已经获准用于个案的法律规则包，也不包含真实案件资料。

`registry.json` 中的 URL 已于 2026-08-10 通过官方站点发现流程核对。任何条目在 `formal_snapshot_status` 仍为 `NOT_CAPTURED` 时，只能帮助研究人员定位材料，不能进入正式计算、文书或提交包。

正式使用必须依次完成：

1. 从登记的官方 HTTPS 域名取得精确响应；
2. 把响应原字节写入本机加密内容寻址对象库；
3. 保存抓取时间、媒体类型和 SHA-256；
4. 由主办律师或复核人核对发布主体、版本、条款定位、有效状态与许可；
5. 通过持久化命令登记 `official_legal_source_snapshot`；
6. 基于该快照批准 `legal_rule_version`；
7. 结合本案已批准事件日期生成并批准唯一 `CaseLegalBundle`；
8. 计算服务只读取服务端从该规则包派生的期间和年利率，不接受浏览器提交任意利率。

网页搜索摘要、律师文章、问答和模型记忆只能作为研究线索。它们不得替代上述快照和审批链。

`capture_probe` 只记录无案件数据的网络可达性和解析冒烟结果。临时目录中的加密对象会随测试清除，不能据此把 `formal_snapshot_status` 改为已捕获。详细安全边界见 `docs/OFFICIAL_SOURCE_CAPTURE_CONTRACT.md`。
