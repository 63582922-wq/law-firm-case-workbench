# 合成证据页处理实验室

这是一个**非生产、可丢弃**的 Phase 0 技术验证，不是证据工作台，也不接受真实案件资料。

它只验证四个将来必须由产品能力承担的底线：

1. 原始 PDF 在产生派生件后，SHA-256 仍保持不变；
2. 在固定渲染参数下，视觉完全相同的页面被识别为同一页级重复组；
3. 与目标名称高度相似但不完全匹配的页面一律标记为人工复核，不能自动删除；
4. 相关页的红框标记只产生一个可追溯的派生 PDF，并能在渲染图中检测到。

## 边界

- 测试夹具全部为英文合成文本，不含客户、法院、账户、手机号、聊天内容或诉讼策略；
- `tmp/` 下的 PDF、PNG、JSON 都是本机临时产物，不会进入 Git；
- 该实验不实现 OCR、人物身份确认、相关性裁决、批量文档接收、权限、数据库、界面或最终提交包；
- “疑似”只表示需要律师决定，绝不表示系统已经确定当事人身份或证据相关性。

## 执行

```sh
PYTHON=/Users/cft/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3
$PYTHON -m unittest labs.evidence_pipeline.test_evidence_pipeline -v
```

测试会在 `tmp/evidence-pipeline/` 中生成合成源文件、页级 Manifest、仅含相关页的 PDF 和红框派生件。

## 通过标准

全部四项测试通过，并人工查看一次渲染后的红框页。任何一项失败，记为实验失败并停止扩展，不以“看起来差不多”替代证据。
