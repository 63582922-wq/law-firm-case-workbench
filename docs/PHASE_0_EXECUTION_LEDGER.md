## 2. 当前禁止事项

在 Phase 0 出口前：

- 不初始化生产 Web 页面、生产数据库迁移或面向真实案件的服务；
- 不把真实客户材料、身份信息、法院文件、诉讼策略或任何凭证放入仓库；
- 不把尚未由律师批准的法律规则或计算结果表述为正式结论；
- 不以私有远程 Git 可克隆为由，跳过受保护主分支和独立加密备份门；
- 不用访谈意向、模型演示或页面截图替代金标准、律师审核和任务通过证据。
- 除非出现能够推翻产品范围或安全边界的新证据，不再进行无明确问题、来源范围和停止条件的公开资料搜索；首轮公开二级研究在本阶段按已完成处理。

## 3. Phase 0 出口核对

只有在下列证据齐备时，才能将本阶段标为完成：

1. 3 个金标准案件能由另一名律师按 Manifest 独立复核；
2. 关键业务、计算、期限、法源、权限和外部调用契约均有责任人和批准人；
3. 研究数据给出实际耗时、错误风险、购买门槛和停止信号；
4. 私有远程、受保护合并控制、独立加密备份和恢复演练均通过；
5. Phase 1 的参与者、样本、任务、观察记录和重测规则可由另一团队复现；
6. 未解决问题都进入风险或决策清单，未被提示词或口头约定掩盖。

## 4. 唯一下一目标

对外部证据而言，唯一下一目标仍是：招募并完成目标律师访谈，同时由执业律师提供和标注首批脱敏金标准案件。没有这两类证据，继续扩展生产功能只会把当前假设固化成产品。其间仅允许按总计划第 3.4 节完成范围固定、可丢弃、无真实数据的技术验证；当前只执行一项“合成证据页处理实验室”，通过或失败后即关闭，不滚动增加同类检查。
