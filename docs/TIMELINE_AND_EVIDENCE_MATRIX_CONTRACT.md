# 时间线与事实—争点—证据矩阵契约

状态：`内部合成 Alpha 领域契约；待真实律师流程验证`

## 时间线

- 借款、付款、利息支付、违约、起诉、受理、送达与关键沟通以独立 `TimelineEvent` 保存。每一事件必须关联至少一个经确认事实和原始证据位置。
- 日期精度明确为精确日期、日期范围或未知。系统可以保留“未知日期”，但不能以文件时间、聊天排序或模型猜测填成精确日期。
- 事件只有在当前已批准事实快照中仍有对应确认事实时才能被律师确认；事实快照变化后，旧事件自动成为不可用于正式快照的失效版本。

## 证据矩阵

- 每条矩阵项注明证明的事实、对应诉请/争点、证据用途、举证责任主体和原始页级证据。举证责任可标为原告、被告或待明确，系统不得自行把它改成法律结论。
- 矩阵项必须绑定当前事实快照哈希。事实、诉请或争点变化后，旧矩阵项不能被重贴为当前版本；需重新核验和确认。
- 每个经确认争点至少需要一条已确认矩阵项。该项表示“已建立证据工作关系”，并不表示该证据足以证明该事实，也不替代律师的证明力判断。

时间线和矩阵仅使用已确认案件对象，尚未接入真实材料抽取、长期存储、UI、文书段落或法院提交包；这些后续连接同样必须沿用来源、版本和律师确认边界。
