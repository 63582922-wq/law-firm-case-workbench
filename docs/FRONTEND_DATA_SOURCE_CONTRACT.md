# 中文工作台数据源契约

状态：`事实、证据、法律规则、正式计算与提交材料页的合成/持久化显式分流已实现；证据页写审批已接入，真实会话和原件影像未接入`

## 显式模式

中文工作台只接受三个可见状态：

1. `synthetic-alpha`：默认，本机合成 API 与固定合成角色；
2. `persistent-preview`：读取独立持久化 API 的 UUID 案件快照，并携带服务端会话 Cookie；
3. `persistent-disabled`：配置缺失、案件 UUID 无效或服务地址不安全时停止读取。

持久化模式失败或未配置时不得回退到合成数据，也不得继续显示合成案情、期限或身份为当前案件。界面明确显示数据源、案件版本、快照哈希和请求号；错误显示“未启用/未连接”，不显示假成功。

## 浏览器安全边界

- 持久化服务必须使用 HTTPS；仅 `localhost`、`127.0.0.1` 或本机 IPv6 地址允许 HTTP；
- 浏览器配置中只保存公开服务地址和案件 UUID，不保存数据库地址、API Key、用户令牌或密码；
- 持久化请求不发送 `X-Actor`，身份来自服务端会话与数据库案件成员关系；
- 合成确认按钮只在合成模式出现，持久化候选显示为需要版本化审批，不伪造前端成功。
- 证据页持久化模式已接入页级处置候选/批准、既有红框候选批准、重复页裁决和 Manifest 锁定；每次写入绑定当前案件版本、证据快照和浏览器计算的审批输入哈希，成功后重新读取服务端快照。连接在回执前中断时不自动重试，页级处置候选会在快照中恢复；新候选建立时只失效旧候选，不覆盖已批准决定或原件。
- 证据派生件只在 `persistent-preview` 且状态为 `VERIFIED` 时显示本机预览/下载；前端用一次性 Bearer 读取、核对响应 SHA-256，在内存 Blob 中预览并在关闭时释放。
- 生成动作只在当前 Manifest 已锁定且没有排队、运行或成功任务时出现；请求绑定案件版本、Manifest 哈希和浏览器计算的批准输入哈希。连接在回执前中断时不自动重试，要求先刷新任务状态。
- 持久化利息页只读取指定债务单元的当前正式计算快照；未选择债务单元、服务未配置或不存在 `VERIFIED` 运行时只显示空状态或阻断原因，绝不调用合成计算 API 补齐金额。
- 法律规则页在持久化模式只读取 `/legal-review` 的版本化快照；浏览器不提交正式利率。合成模式仅展示真实官方 URL 的“发现清单”，每项明确标记 `NOT_CAPTURED`、无内容哈希且不可进入规则包。
- 官方法源抓取状态由独立 `/official-source-captures` 快照读取，抓取服务缺失不会让只读法律页回退到冒烟记录。持久模式只有在律师明确勾选“只访问公开官方网站且不发送案件材料”后才显示可用入队动作；请求绑定案件版本、固定最小查询哈希和授权输入哈希，连接中断不自动重试。
- 抓取结果仅显示官方 URL、状态、内容/解析/捕获回执哈希和经过最小化的结构摘要，不返回加密对象键、授权哈希或租约标识。只有 `REVIEW_REQUIRED` 运行显示批准/驳回；复核哈希绑定案件版本、运行、内容、解析输出、决定和官方原文定位。
- “批准进入登记步骤”不是正式登记。已批准运行还须填写公开访问、加密保存和案内使用依据，前端把依据、内容哈希、解析哈希、复核哈希与案件版本分别绑定为许可复核哈希和登记哈希，再调用专用登记端点。登记成功只刷新正式来源快照，不自动创建规则或计算。
- 提交材料页在持久化模式只读取 `/submission-snapshot`；页面不暴露加密对象键。只有当前 `VALID + EXPORTED` 导出对主办/复核律师显示下载动作，下载使用 OS 绑定会话和 30 秒内一次性本机许可，并在接收后核对媒体类型、长度和 SHA-256。

## 当前显示范围

事实与争点页已统一映射两类快照，明确显示人民币/CNY、付款性质、冲抵应用、候选/确认/失效状态、案件版本、快照哈希和请求号。证据页也已读取独立证据快照，展示全部来源页、逐页纳入/排除、红框坐标、重复组和锁定 Manifest；持久模式不伪造原件影像，但可对已核验相关页/红框派生 PDF 执行本机短时预览和下载。法律规则页展示官方来源、条款位置、核验/许可状态、规则公式、服务端派生利率、法律事件、确认事实锚点和连续规则包。利息页读取正式情景、法律规则包、逐期计算和逐笔冲抵快照，明确显示 `CNY`、独立复算和证据回链。提交材料页展示法院文件、四项正式依赖、锁定状态和已核验导出；合成模式明确阻断下载，不伪造法院提交成功。
