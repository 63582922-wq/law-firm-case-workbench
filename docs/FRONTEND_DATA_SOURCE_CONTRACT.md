# 中文工作台数据源契约

状态：`合成/持久化显式分流、证据审批、受控原件预览与 WebView 短时桌面会话客户端已实现；生产身份和专用数据库未配置`

## 显式模式

中文工作台只接受三个可见状态：

1. `synthetic-alpha`：默认，本机合成 API 与固定合成角色；
2. `persistent-preview`：读取独立持久化 API 的 UUID 案件版本化投影；桌面模式通过原生命令取得动态 loopback 与短时 Bearer，非桌面内部预览才使用服务端会话 Cookie；
3. `persistent-disabled`：配置缺失、案件 UUID 无效或服务地址不安全时停止读取。

持久化模式失败或未配置时不得回退到合成数据，也不得继续显示合成案情、期限或身份为当前案件。界面明确显示数据源、案件版本、快照哈希和请求号；错误显示“未启用/未连接”，不显示假成功。

首页在持久化模式同样不得复用合成案件的总览、金额、期限或模拟审计记录；当正式汇总快照尚未建立时，只显示材料接收与后续版本化工作区入口。

## 浏览器安全边界

- 持久化服务必须使用 HTTPS；仅 `localhost`、`127.0.0.1` 或本机 IPv6 地址允许 HTTP；
- 浏览器配置中只保存公开服务地址和案件 UUID，不保存数据库地址、API Key、用户令牌或密码；
- 持久化请求不发送 `X-Actor`，身份来自服务端会话与数据库案件成员关系；
- 桌面正式请求不把 Bearer 写入 URL、Cookie、localStorage、sessionStorage、普通运行状态或日志；每次请求从原生受控 grant 取得，调用方不能覆盖身份头。服务端 CORS 只允许 `tauri://localhost` 和必要方法/头；会话 401 不自动重试写动作。
- 合成确认按钮只在合成模式出现，持久化候选显示为需要版本化审批，不伪造前端成功。
- 事实与争点页首屏只读案件审查摘要及事实/交易各 50 条，不再下载全量案件快照。摘要版本通过 `expected_version` 绑定两类首批，后续页再由稳定游标绑定同一案件和版本；界面显示已载入数量，冲突时停止拼接并要求重新载入，不自动重试或回退。
- 证据页持久化模式已接入页级处置候选/批准、既有红框候选批准、重复页裁决和 Manifest 锁定；首屏读取全案就绪摘要及前 50 页，后续页由案件版本绑定的稳定游标续载。每次写入绑定当前案件版本和摘要哈希；Manifest 锁定另绑定服务端计算的全案就绪哈希，服务端在写事务内复核全部页、候选处置、红框和重复组。连接在回执前中断时不自动重试，页级处置候选会在刷新后恢复；新候选建立时只失效旧候选，不覆盖已批准决定或原件。
- 原件预览只接受桌面桥返回并经用户二次确认的本地文件夹。前端不保存绝对路径；服务端以案件、操作者、OS 会话、目录指纹和原件 SHA-256 解析登记文件，只向 loopback 浏览器一次性返回当前页 PNG。前端再次核对 PNG 哈希和尺寸，在内存 Blob 中显示并释放。页面可在该 PNG 上拖选标准化坐标、提交红框候选，再由律师批准；不会修改原 PDF。
- 文件夹确认后可建立候选盘点。界面只展示相对路径、脱敏哈希、类型和新增/修改/移动/缺失/未变化计数；超过 100 条按案件版本和扫描 UUID 续载。重新扫描不会自动改变正式范围，主办律师必须勾选确认并批准。界面不提供删除、重命名、移动、覆盖或上传原件的动作；断线时不自动重试扫描/批准。
- 当前已批准范围可在仍有效的本机文件夹授权下建立材料接收任务。界面显示已登记 PDF、等待/处理中、需转换/人工处理、阻断/失败四类计数；明确说明非 PDF 不伪造页数。连接在回执前中断时只刷新状态，不自动重复排队。
- 证据派生件只在 `persistent-preview` 且状态为 `VERIFIED` 时显示本机预览/下载；前端用一次性 Bearer 读取、核对响应 SHA-256，在内存 Blob 中预览并在关闭时释放。
- 生成动作只在当前 Manifest 已锁定且没有排队、运行或成功任务时出现；请求绑定案件版本、Manifest 哈希和浏览器计算的批准输入哈希。连接在回执前中断时不自动重试，要求先刷新任务状态。
- 持久化利息页只读取指定债务单元的当前正式计算快照；未选择债务单元、服务未配置或不存在 `VERIFIED` 运行时只显示空状态或阻断原因，绝不调用合成计算 API 补齐金额。
- 法律规则页在持久化模式读取 `/legal-review` 的版本化快照，并补入同一份经核验的官方来源“仅发现目录”，使尚无正式快照的新案件仍可建立第一项受控抓取任务；发现项明确标记 `NOT_CAPTURED`、无内容哈希且不可进入规则包。浏览器不提交正式利率，已登记来源不被发现目录覆盖。
- 官方法源抓取状态由独立 `/official-source-captures` 快照读取，抓取服务缺失不会让只读法律页回退到冒烟记录。持久模式只有在律师明确勾选“只访问公开官方网站且不发送案件材料”后才显示可用入队动作；请求绑定案件版本、固定最小查询哈希和授权输入哈希，连接中断不自动重试。
- 某些来源登记了经验证、可被同一确定性解析器识别的官方备用页时，页面让律师在入队前明确选择主页面或备用官方页，所选完整 URL 进入授权和捕获回执；没有可解析备用页的来源不显示伪备用选项，抓取失败保持失败并等待后续合规处理。
- 抓取结果仅显示官方 URL、状态、内容/解析/捕获回执哈希和经过最小化的结构摘要，不返回加密对象键、授权哈希或租约标识。只有 `REVIEW_REQUIRED` 运行显示批准/驳回；复核哈希绑定案件版本、运行、内容、解析输出、决定和官方原文定位。
- “批准进入登记步骤”不是正式登记。已批准运行还须填写公开访问、加密保存和案内使用依据，前端把依据、内容哈希、解析哈希、复核哈希与案件版本分别绑定为许可复核哈希和登记哈希，再调用专用登记端点。登记成功只刷新正式来源快照，不自动创建规则或计算。
- 提交材料页在持久化模式读取 `/submission-snapshot`、`/document-consistency-reviews` 和内部文书审阅快照；页面不暴露加密对象键、文书正文或律师确认值。文书一致性区只显示当前审查的版本、输入/输出哈希、阻断/提示数量和安全发现代码，并明确提示 QA 必须重新核对当前 `PASS` 与精确覆盖集。Word/Excel 草稿先经 `reviewable-office-drafts/{pair}/access` 签发绑定当前 OS 会话与草稿对的一次性许可，再从 loopback 读取 PDF 审阅稿或可编辑件；前端核对内容类型、长度和 SHA-256，确认动作只提交当前共同复核哈希。只有当前 `VALID + EXPORTED` 导出对主办/复核律师显示法院 ZIP 下载动作，下载使用 OS 绑定会话和 30 秒内一次性本机许可，并在接收后核对媒体类型、长度和 SHA-256。

## 当前显示范围

事实与争点页已统一映射两类数据源；持久模式读取案件摘要与版本绑定的事实/交易分页，明确显示人民币/CNY、付款性质、冲抵应用、候选/确认/失效状态、案件版本、投影哈希、载入数量和请求号。证据页读取全案就绪摘要和版本绑定的来源页分页，显示“已载入/总页数”、全案阻断计数、逐页纳入/排除、红框坐标、重复组和锁定 Manifest；中断保留已载入页并允许续载。持久模式不伪造原件影像，但可对已核验相关页/红框派生 PDF 执行本机短时预览和下载。法律规则页展示官方来源、条款位置、核验/许可状态、规则公式、服务端派生利率、法律事件、确认事实锚点和连续规则包。利息页读取正式情景、法律规则包、逐期计算和逐笔冲抵快照，明确显示 `CNY`、独立复算和证据回链。提交材料页展示法院文件、同文书获批新版本后自动过期的旧版及固定失效原因、四项正式依赖、锁定状态和已核验导出；合成模式明确阻断下载，不伪造法院提交成功。

身份安全页已提供在线激活、离线登记包导入、续期、远程撤销和“只停用本机”的分离操作：在线激活只调用无参数原生命令，激活码进入 macOS 安全输入框而非页面；续期不热替换当前会话；远程撤销需页面二次点击与 macOS 原生警告框，并只在服务端接受后清除本机凭证；本机停用不冒充远程撤销。生产信任未配置时这些远程动作禁用。真实生产服务、专用数据库、恶意 PDF 隔离验收、正式规则编辑审批、下载事件持久审计和律师可用性测试仍未完成。没有桌面桥时页面明确阻断选择动作，不提供手填绝对路径的旁路。`/legal` 与 `/bundle` 已完成本机浏览器加载、阻断状态、1280px 无横向溢出和导航检查；这不替代真实身份、实库、真实案卷和律师验收。

身份与安全页还只读显示本案 Agent 审计账本：运行计划、Skill/Tool、策略哈希、输入版本、范围、审批门和执行结果。前端不显示提示词、案卷正文、对象键、令牌或模型供应商凭证，也不提供绕过系统 Worker 的“立即执行”入口；未配置审计服务时向律师显示阻断原因。
