# 中文工作台数据源契约

状态：`事实、证据、法律规则与正式计算页的合成/持久化显式分流已实现；真实会话和原件影像未接入`

## 显式模式

中文工作台只接受三个可见状态：

1. `synthetic-alpha`：默认，本机合成 API 与固定合成角色；
2. `persistent-preview`：读取独立持久化 API 的 UUID 案件快照，并携带服务端会话 Cookie；
3. `persistent-disabled`：配置缺失、案件 UUID 无效或服务地址不安全时停止读取。

持久化模式失败或未配置时不得回退到合成数据，也不得继续显示合成案情、期限或身份为当前案件。界面明确显示数据源、案件版本、快照哈希和请求号；错误显示“未启用/未连接”，不显示假成功。

## 浏览器安全边界

- 持久化服务必须使用 HTTPS；仅 `localhost`、`127.0.0.1` 或本机 IPv6 地址允许 HTTP；
- 浏览器配置中只保存公开服务地址和案件 UUID，不保存数据库地址、API Key、用户令牌或密码；
- 持久化请求不发送 `X-Actor`，身份来自服务端会话与数据库案件成员关系；
- 合成确认按钮只在合成模式出现，持久化候选显示为需要版本化审批，不伪造前端成功。
- 证据派生件只在 `persistent-preview` 且状态为 `VERIFIED` 时显示本机预览/下载；前端用一次性 Bearer 读取、核对响应 SHA-256，在内存 Blob 中预览并在关闭时释放。
- 生成动作只在当前 Manifest 已锁定且没有排队、运行或成功任务时出现；请求绑定案件版本、Manifest 哈希和浏览器计算的批准输入哈希。连接在回执前中断时不自动重试，要求先刷新任务状态。
- 持久化利息页只读取指定债务单元的当前正式计算快照；未选择债务单元、服务未配置或不存在 `VERIFIED` 运行时只显示空状态或阻断原因，绝不调用合成计算 API 补齐金额。
- 法律规则页在持久化模式只读取 `/legal-review` 的版本化快照；浏览器不提交正式利率。合成模式仅展示真实官方 URL 的“发现清单”，每项明确标记 `NOT_CAPTURED`、无内容哈希且不可进入规则包。

## 当前显示范围

事实与争点页已统一映射两类快照，明确显示人民币/CNY、付款性质、冲抵应用、候选/确认/失效状态、案件版本、快照哈希和请求号。证据页也已读取独立证据快照，展示全部来源页、逐页纳入/排除、红框坐标、重复组和锁定 Manifest；持久模式不伪造原件影像，但可对已核验相关页/红框派生 PDF 执行本机短时预览和下载。法律规则页展示官方来源、条款位置、核验/许可状态、规则公式、服务端派生利率、法律事件、确认事实锚点和连续规则包。利息页读取正式情景、法律规则包、逐期计算和逐笔冲抵快照，明确显示 `CNY`、独立复算和证据回链。提交材料仍待接入持久数据源；在持久模式下页头继续遮断合成案情、合成期限和合成金额。
