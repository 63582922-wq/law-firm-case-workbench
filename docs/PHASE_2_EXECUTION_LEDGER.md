## 当前禁止事项

- 不接入真实客户、法院、身份、账户、聊天或诉讼策略数据；
- 不把内存仓库、合成 PDF 实验或自动检查描述为生产服务；
- 不调用外部模型、OCR、MCP 或 SaaS 处理案件数据；
- 不使用真实案件生成、签章、发送或上传法院材料；合成编译器输出不称为真实可提交文件；
- 不因尚未完成真实验证而停止合成 Alpha 的开发。

## 下一目标

下一步在不接入真实数据的前提下实现大案分页、最小展示和长列表恢复边界，并继续收紧桌面持久 API/Worker/Store 的正式装配入口。生产演练仍需律所确定生产根保管/门限/轮换仪式、签发服务域名、TLS SPKI 及管理员/MFA 流程；专用 PostgreSQL 实迁移和逐案权限整链仍需要获授权的 `_test` 数据库。没有真实签发身份和专用数据库时继续保持案件路由关闭。
