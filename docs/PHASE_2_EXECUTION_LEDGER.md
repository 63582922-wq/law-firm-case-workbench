## 当前禁止事项

- 不接入真实客户、法院、身份、账户、聊天或诉讼策略数据；
- 不把内存仓库、合成 PDF 实验或自动检查描述为生产服务；
- 不调用外部模型、OCR、MCP 或 SaaS 处理案件数据；
- 不生成可向法院提交的文书或提交包；
- 不因尚未完成真实验证而停止合成 Alpha 的开发。

## 下一目标

开始把已完成的合成领域对象接入受控 API 和中文工作台：先提供只读快照、候选/确认动作的版本化契约和状态阻断提示，再实现事实与交易台账界面；不开放真实案卷、外部模型或法院提交输出。并在获得专用 `_test` 数据库授权后执行 PostgreSQL 迁移与集成检查，始终保持真实案件接入门槛不变。
