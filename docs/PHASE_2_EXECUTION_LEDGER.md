## 当前禁止事项

- 不接入真实客户、法院、身份、账户、聊天或诉讼策略数据；
- 不把内存仓库、合成 PDF 实验或自动检查描述为生产服务；
- 不调用外部模型、OCR、MCP 或 SaaS 处理案件数据；
- 不使用真实案件生成、签章、发送或上传法院材料；合成编译器输出不称为真实可提交文件；
- 不因尚未完成真实验证而停止合成 Alpha 的开发。

## 下一目标

下一步把证据逐页纳入/排除、红框和重复结论的前端写审批接入同一版本化命令边界，并补齐原件安全图像读取。Keychain 初始化/轮换、桌面常驻 Worker、真实 OS 身份和持久下载审计仍是桌面安装边界。没有专用 `_test` 数据库和真实身份基础设施时继续使用合成夹具验证，但不把它描述为 PostgreSQL 实库、真实登录或真实案卷验收。
