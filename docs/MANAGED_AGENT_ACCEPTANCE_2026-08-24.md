## 本轮修正

1. Qwen 只返回不可信 OCR 文字，来源 ID、页码和哈希由服务器投影绑定。
2. 台账提取显式读取直接视觉依赖，并把 OCR 来源强制标记为 `OCR_DERIVED`、`UNTRUSTED_TEXT`。
3. 迁移 `0059` 将数据库 exchange 防篡改门与当前运行时策略哈希同步；Worker 启动预检会拒绝策略漂移。
4. OpenAI 兼容响应信封只在传输层拆解一次；任务适配器直接验证有界 UTF-8 OCR 文本。

相关 OCR/传输/数据库聚焦测试 36 项通过；策略哈希启动预检通过。此前 OCR→台账桥相关测试 106 项通过。
