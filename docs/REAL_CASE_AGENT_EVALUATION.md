## 一、结论

**Agent 作为"材料粗筛助理"可用：提取、引用、分类纪律、规律识别均达到可用水平；作为"判断者"不可独立使用：方向误判顽固、资金性质判断需人工把关。当前正确的使用方式 = AI 提议 + 律师审批 + 确定性计算（本轮已按此流程完整跑通）。**

## 六、遗留工程问题（下轮修复）

1. dry-run 模式 OCR 文本未合并 → 摘录校验误报；应允许 dry-run 复用 OCR 缓存。
2. 方向判断靠提示词不可靠 → 计划改为解析层确定性规则（amount 符号 + 渠道 + memo 关键词）与模型分类交叉校验，冲突即阻断升级。
3. 银行组金额带负号、微信组为正数 → 归一化规则需按渠道区分。
