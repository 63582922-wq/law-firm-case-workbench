# 案卷材料接收 Worker 契约

状态：`合成 Alpha 的批准范围、逐文件队列、PDF 登记、非 PDF 有界结构检查和可见异常队列已实现；真实恶意文件扫描器、常驻 Worker、隔离转换和真实案卷验收未配置`

## 目的

把主办律师已批准的本机案卷范围转为正式不可变原件和页级对象。浏览器不能自行填写媒体类型、页数或“安全”结论；原件不会被上传、改名、移动、删除或覆盖。

## 建立任务

主办律师只能对当前 `APPROVED` 的文件夹盘点建立一个接收任务。请求必须同时绑定案件版本、扫描 UUID、Manifest 哈希、律师批准哈希和仍有效的本机文件夹 grant。服务端在排队前重新只读扫描目录；当前 Manifest 与批准哈希不一致时停止，要求重新盘点和批准。

数据库只保存相对路径、预期字节数/SHA-256、检测类型、任务/项目状态、短租约、扫描器版本、检查哈希和登记结果。绝对路径、文件夹 grant、OS 会话和 ClamAV 命令输出不落库。

## 逐文件处理

1. `SYSTEM_WORKER` 以 30—300 秒租约领取一项；过期租约最多恢复三次，心跳不改变案件业务内容。第三次租约仍过期时，专用 reaper 将项目明确标为 `RECOVERY_ATTEMPTS_EXHAUSTED`，避免任务永久卡在运行中。
2. 当前人类案件成员的 OS 绑定文件夹 grant 按相对路径解析文件，再次核对目录设备/inode、文件大小和 SHA-256；系统 Worker 不能自行取得任意文件系统权限。
3. 必须运行显式配置的本机恶意文件扫描器。当前适配器只接受绝对路径的非符号链接 ClamAV 可执行文件，使用参数数组而非 Shell；记录扫描器和病毒库/版本标识。未配置或不可用时不把文件标为安全。
4. PDF 必须具有正确签名、可严格解析、未加密、页数在上限内、页面几何有效，且不含 JavaScript、自动打开动作、Launch、嵌入文件、表单提交、音视频等活动内容。
5. 通过检查的 PDF 才能用真实页数登记 `evidence_original_files` 和 `evidence_pages`，再把接收项标记为 `REGISTERED`。登记和项目完成使用稳定幂等键。
6. 图片、Word、Excel、文本、邮件和压缩包不会被伪造成一页 PDF。恶意文件扫描通过后还会执行有界结构检查：图片校验真实格式/单帧/像素规模；OOXML 阻断宏、ActiveX、嵌入对象、外链和主动 XML；ZIP 阻断危险路径、符号链接、加密、条目/展开大小和异常压缩比；文本与 EML 校验编码、结构及附件名。通过者进入 `REVIEW_REQUIRED`，危险、损坏或签名不符者进入 `BLOCKED`。
7. 新案卷范围获批后，旧接收任务和项目统一转为 `STALE`；已登记原件仍保留，不删除历史证据。

## 可见状态

中文证据页显示汇总，并以案件版本绑定的最多 100 项分页展示相对路径、文件类型、处理状态、尝试次数和稳定中文原因。租约 ID、绝对路径、源文件哈希、扫描器详细输出和文件内容不进入页面。`PARTIAL` 不等于处理成功，必须清空需处理和阻断项后才能进入全量页级核验。
