# 界面怎么用（本机模式，四步走）

本机工作台只做四件事，全部在**案件首页的「本机办案流程（四步）」卡片**上，每步一个按钮：

| 步骤 | 在哪里 | 你要做什么 | 产出 |
|---|---|---|---|
| ① 材料入卷 | 材料与证据 | 点「选择 PDF」或拖入文件 → 点「开始接收 N 份材料」 | 材料受理回执、页级记录 |
| ② 生成决策包 | 决策包 | （可选）填计算参数 → 需要时勾选「扫描件图像原样发送」→「开始分析」 | 案件决策包（Markdown / Word），含正式数字 |
| ③ 生成答辩状草稿 | 答辩状 | 勾选主张、逐项选择对诉请的态度、登记法条 → 「保存并生成草稿」 | 答辩状草稿（Word） |
| ④ 导出应诉材料包 | 交付清单 | 填当事人信息、逐项更新状态 → 「导出应诉材料包（Word）」 | 一整套应诉材料（含 7 份需当事人签字的文件） |

## 界面上的几个说法

- **顶部导航**：只显示本机能用的环节（案件首页／材料与证据／决策包／答辩状／交付清单）；
  「确认案情 · 依据与测算 · 金额核对 · 成果文件」属于服务器模式，本机不显示，避免出现点不动的灰项。
- **每页标题下的「这一步怎么做」**：就是该页的操作说明，照着做即可。
- **案件首页的四步卡片**：每步都显示当前状态（未生成／已完成／已失效…），点按钮直接进对应页面。
- **左侧案件列表**：先点一个案件；没选案件时右侧会提示"先点左侧任意案件"。

## 顺序上的两个硬约束

1. **决策包需要先有材料**；**答辩状需要先有决策包**（它用决策包的争点与正式数字写论证）；
2. **材料或参数变了，前面的结果会标记「已失效」**，需要重新运行对应步骤——这是有意为之，
   避免拿旧数字写新文书。

## 费用与数据

- 只有第 ② 步（决策包）和第 ③ 步（答辩状）会调用模型：单次约 ¥0.05，页面会写明；
- 第 ① 步与第 ④ 步**不调用模型、不产生费用**；
- 所有结果都保存在本机案卷目录，报告与账本（`preflight.json`、`*_ledger.json`）同目录留档。
