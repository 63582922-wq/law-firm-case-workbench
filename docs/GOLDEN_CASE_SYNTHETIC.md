# 合成金标准案件规格（垂直切片验收基准）

状态：`v1 · 已由独立复算器生成金标准数字 · 待 Codex 按本规格实现并复现`

> 本规格服务于第一个可运行垂直切片（见用户向 Codex 提供的提示词第 3 点展开）。
> 全部案件数据均为**合成虚构**：案号、姓名、证件号、手机号、账号、金额均不来自任何真实案件。
> 禁止以真实客户材料替换或混入。本规格不是 Phase 0 真实金标准案件数据包的替代品。

---

## 1. 用途与验收方式

Codex 实现切片时，以本规格为唯一输入基准：

1. 按 §4 生成全部材料文件（合成），按 §7 生成交易台账输入；
2. 实现确定性计算引擎，输出必须与 `docs/golden-case/golden_calc.py` 的输出**逐分一致**；
3. 六项智能验收指标按 §10 逐项报实测数字；
4. 任何与本规格不一致处，必须作为缺陷报告，不得自行"修正"金标准。

独立复算：`python3 docs/golden-case/golden_calc.py`，任何人可在无 AI 参与下重跑验证。

## 3. 冻结规则（中国标准，计算引擎必须逐条实现）

| 编号 | 规则 | 法源 |
|---|---|---|
| R0 | 自然人之间借款合同自贷款人提供借款时成立；本案两笔均以银行转账交付，成立日 = 转账日 | 《民法典》第 679 条 |
| R1 | 计息：日利率 = 约定月利率 ÷ 30，按实际日历天数，算头不算尾（起始日含、截止日不含），北京时间 | 冻结口径（司法实践按月利率÷30 折算，见 §4 法源表） |
| R2 | 利率保护上限：2020-08-20 起（含当日）为起诉时一年期 LPR × 4 = 3.00% × 4 = **年 12%（月 1%）**；此前为 **年 24%（月 2%）** | 法释〔2020〕17号 第 31 条；法释〔2015〕18号 第 26 条 |
| R3 | 冲抵顺序：实现债权费用 → 利息 → 本金；本案费用为 0 | 《民法典》第 561 条 |
| R4 | 老区间（<2020-08-20）已付利息：年 24% 内受保护；24%–36% 为自然债务（已付不退不冲）；超过年 36%（按月 3%，以付款时未偿本金为基数）部分**冲抵本金** | 法释〔2015〕18号 第 26 条 |
| R5 | 新区间（≥2020-08-20）已付利息超过月 1% 部分，冲抵本金 | 法释〔2020〕17号 第 31 条之适用结果 |
| R6 | 逾期利息：借期内有约定利率的，逾期按借期内利率计（受 R2 上限约束）；未定期限借款，出借人可随时要求返还 | 《民法典》第 675 条；法释〔2020〕17号 第 28 条 |
| R7 | 借款人单方注明"还本金"不改变法定冲抵顺序（除双方另有约定外） | 《民法典》第 561 条"除当事人另有约定外" |
| R8 | 数项债务未指定清偿顺序时，优先履行已到期债务；L1 于 2020-06-02 到期，L2 未定期限 → 未指定还款先冲 L1 | 《民法典》第 560 条 |
| R9 | 金额以"分"为最小单位；每段利息、每笔冲抵额独立四舍五入到分（ROUND_HALF_UP）；本金余额逐笔递减 | 冻结口径 |
| R10 | 诉讼时效 3 年；部分还款、同意履行构成中断 | 《民法典》第 188、195 条 |

### 时态利率适用（本案）

- **借款 1（L1）**：约定月息 2 分（年 24%）。2019-06-03 至 2020-08-19 按月 2% 计（恰在上限内，受保护）；2020-08-20 起按月 1%（上限）计。
- **借款 2（L2）**：约定月息 3.5 分（年 42%）。老区间：受保护上限月 2%，24%–36% 带为自然债务，超过月 3% 部分逐笔冲本金；新区间：受保护上限月 1%，超额逐笔冲本金。
- 起诉时一年期 LPR = **3.00%**（[2025-05-20 公布](https://www.pbc.gov.cn/zhengcehuobisi/125207/125213/125440/3876551/5714282/index.html)），4 倍 = 年 12%。
