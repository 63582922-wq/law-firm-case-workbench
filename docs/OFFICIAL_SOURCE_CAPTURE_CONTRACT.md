# 官方法源抓取与解析契约

状态：`公开官方来源真实网络冒烟已通过；持久队列、一次执行 Worker 与律师复核 UI 已实现，尚未在专用实库形成个案正式法源快照`

## 抓取边界

每次外部请求必须先由研究网关生成最小化检索计划，并由律师明确授权具体来源和完整 HTTPS URL。查询词禁止包含手机号、身份证号、银行卡号、邮箱等案件敏感数据。抓取器不携带律所 Cookie、账号、API Key 或案件文件。

真实请求只允许注册官方域名、443 端口和无账号密码的 HTTPS。连接后检查实际对端必须是公网 IP，TLS 证书使用系统信任链验证；重定向不自动跟随，须重新授权规范最终 URL。响应限制媒体类型、Content-Length、实际字节数和内容签名，默认上限 32MB。

## 加密与审计

响应原字节在内存中计算 SHA-256，并直接写入 AES-256-GCM 本机内容寻址对象库，不在案件原文件夹落地明文。抓取回执绑定研究计划、授权请求、查询哈希、URL、抓取时点、媒体类型、字节数、内容哈希、加密对象键和实际对端 IP。

成功抓取后的固定状态是 `HUMAN_REVIEW_REQUIRED`。抓取或解析成功不等于法律有效性、版本、许可和个案适用已经批准；只有主办律师或复核律师通过独立持久化命令登记后，来源才可能进入规则包。

## 持久队列与桌面执行

`0008_official_source_capture_runs.sql` 保存律师授权的具体来源、完整 URL、最小查询哈希、授权绑定、15 分钟授权窗口、一次尝试和 30—300 秒 Worker 租约。队列不会保存查询原文，更不会接收案件姓名、电话、身份证、银行卡或案卷正文。

专用 `SYSTEM_WORKER` 领取任务后，重新生成固定公开查询并核对哈希，再执行 credential-free TLS 抓取、原字节加密和确定性解析。完成回执绑定案件、运行、律师授权哈希、官方 URL、内容哈希、实际公网对端、解析器及解析输出；成功只进入 `REVIEW_REQUIRED`。安全抓取或解析失败只写入稳定失败码，不把网页正文或底层异常写入案件审计。

中文 `/legal` 页面把发现链接、开发机真实网络冒烟和案件持久队列分开显示。正式模式必须先勾选“只访问公开官方网站且不发送案件材料”，再授权具体来源；律师复核前必须打开本次授权 URL 并填写可回到官方原文的条文/记录位置。批准仅进入后续登记步骤，不自动创建法源快照、规则或利息计算。

律师批准抓取结果后，仍须执行独立“正式法源登记”命令并填写公开访问、加密保存、律所内部研究/诉讼引用与再分发边界等许可核验依据。服务端从数据库读取捕获对象键，重新解密并核对原字节哈希，再把捕获回执、解析输出、律师复核、许可复核和登记输入共同绑定到正式快照；浏览器不能提交或读取对象键。`0009` 允许旧预览记录保持可读，但缺少许可依据/哈希的旧快照不能支撑新的规则或规则包审批，系统不自动补造历史许可结论。

## 当前确定性解析器

- 最高人民法院 2020 年第二次修正长页面：先锚定重新公布的《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》及两次修正历史，再提取第 25、31 条；页面中其他司法解释的同号条文不会被误取。
- 最高人民法院 2020 年第一次修正历史文本：锚定 2020-08-20 施行标识，提取第 26 条“合同成立时 LPR 四倍”及第 32 条“2019-08-20 前借贷行为/原告起诉时”历史过渡表述，保留为历史版本而不覆盖第二次修正。
- 法释〔2015〕18号解析器：第 26 条未付利息保护/无效区与第 31 条已自愿支付/不当得利路径分别生成候选，避免把已付利息和未付利息混为一个上限。
- 《中华人民共和国民法典》最高人民法院公开全文：核对标题、2020-05-28 通过日期和条文顺序，再提取第 679、680 条。
- 中国货币网 LPR JSON：核对官方响应码、日期、1Y/5Y 字段、数值范围、重复日期并生成不重叠有效期间；网页公告则要求恰好出现一条完整发布日期、1 年期和 5 年期以上 LPR 陈述。

以上解析产物均保存输入内容哈希、条文/记录定位、语义哈希和解析输出哈希，状态仍为 `HUMAN_REVIEW_REQUIRED`。
