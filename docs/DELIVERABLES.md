# 交付：应诉材料包（每份独立、排版统一）

状态：`v2 · 已按律师交付标准重做`

## 1. 之前错在哪（v1 的问题）

- 把所有内容塞进**一个 Word**：答辩状、签字文件、证据目录、说明文字混在一起；
- 文书里混进**系统话术**："本文件由系统生成""律师工作稿""见计算表""待核清单"；
- 排版不统一：Markdown 残留、表格无框线、列宽错乱、字体未指定；
- **证据目录把全部入卷材料都当成"我方证据"**——包括法院送达的传票、应诉通知书，
  这在实务上是错的；
- 界面上堆了十来个选填项，律师看不出该做什么。

## 2. 现在交付什么（一个 ZIP，内部按用途分开放）

```text
应诉材料包_<案号>_<案由>/
├── 01-民事答辩状.docx                    需答辩人签名
├── 02-证据目录.docx                      补"证明内容"
├── 03-质证意见.docx                      逐份三性意见
├── 04-代理词.docx
├── 05-授权委托书（当事人签字）.docx        当事人本人签字
├── 06-送达地址确认书（当事人签字）.docx    当事人本人签字
├── 07-当事人陈述（当事人签字）.docx        当事人本人签字
├── 08-证据来源说明（当事人签字）.docx      当事人本人签字
├── 09-调解意见确认（当事人签字）.docx      当事人本人签字
├── 使用顺序.txt                          先签哪些、后交哪些
├── 申请书（按需选用）/
│   ├── 10-申请书（追加当事人）.docx
│   ├── 11-申请书（调查取证）.docx
│   ├── 12-申请书（鉴定）.docx
│   └── 13-申请书（延期举证）.docx
└── 内部文件（不提交）/
    └── 交付清单与填写指引.docx            律师自己看，不要交法院
```

## 3. 排版规范（写死在渲染器里）

| 项目 | 设定 |
|---|---|
| 纸张/页边距 | A4，上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm |
| 文书标题 | 宋体 二号（22pt）加粗居中 |
| 一级小标题 | 黑体 三号（16pt） |
| 正文 | 宋体 三号（16pt），行距固定值 28pt，首行缩进 2 字 |
| 表格 | 宋体 四号（14pt），单线边框（显式写 tblGrid + fixed 布局，Word/WPS 都不会跑版） |
| 颜色 / 图标 | **一律没有**；不用 Markdown 符号 |
| 页码 | 页脚居中 |

字体默认用**宋体 / 黑体**：Windows（SimSun/SimHei）与 macOS（Songti SC/Heiti SC）都有对应，
不会出现方框。律所若统一要求公文仿宋，可用环境变量覆盖：

```text
CASE_WORKBENCH_DOC_FONT_BODY=仿宋_GB2312
CASE_WORKBENCH_DOC_FONT_TITLE=宋体
CASE_WORKBENCH_DOC_FONT_HEADING=黑体
```

## 4. 提交件里绝不出现的字样

`由系统生成`、`律师工作稿`、`见计算表`、`待核清单`、`【待填】`、门禁等级、
`[依据待律师登记]`。这些一律改写为**手写空白**（`＿＿＿＿`），位置集中登记在
「内部文件（不提交）」里，由律师按计算表填写。

## 5. 材料归类：谁是证据由律师勾选

- **原告证据** → 进「质证意见」；**我方证据** → 进「证据目录／证据来源说明」；
- 不勾选就不进文书。**法院送达文书（传票、通知书）永远不会被当成证据**；
- 系统内部用哈希命名的上传件（如 `12207299bbcf….jpg`）不写进正式文书，
  证据名称留空由律师填写。

## 6. 界面（只剩三件事）

1. **填四项基本信息**：答辩人、原告、受理法院、案号（案由与住所等可选）；
2. **勾选证据**：每份材料两个勾——原告证据 / 我方证据；
3. **导出应诉材料包（ZIP）**：材料包里每份文书都可单独下载。

## 7. 实测（合成木业真实案卷）

- 材料 23 份 / 73 页；勾选 2 份为我方证据、5 份为原告证据；
- 导出 ZIP 约 495 KB，含 13 份文书 + 内部文件 + 使用顺序；
- 逐份检查：字体仅 宋体/黑体、**零颜色**、无系统话术、表格有框线、列宽固定；
- 用 macOS Quick Look（真实字体渲染）肉眼核对答辩状、证据目录、质证意见版式。

## 8. 仍需律师处理的

- 所有 `＿＿＿＿`：事实、证明内容、三性意见、代理意见、法条；
- 答辩状"事实与理由"是模型起草的论证文字，**必须逐句核对改写后再用**；
- 签字文件必须当事人本人签署（系统不代签、不代作事实陈述）。
