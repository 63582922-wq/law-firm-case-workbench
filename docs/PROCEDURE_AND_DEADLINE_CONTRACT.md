# 法院材料、送达与程序期限契约

状态：`内部合成 Alpha 领域契约；待真实律师流程验证`

本模块不是“自动告诉律师截止日期”的功能。它只按律师已批准的规则配置和已确认事实，生成待确认的期限候选。

## 1. 法院材料与送达事实

- 法院名称、案号、送达方式、送达日期均先是带原始证据位置的候选；案号相似、文件名、截图时间或文件系统时间都不能自动成为已确认送达事实。
- 只有律师确认的法院案件可承载律师确认的送达记录。日期非精确、送达方式不明或证据失效时，系统阻断期限候选，而不是显示倒计时。
- 上游法院案件或送达记录失效时，相关期限候选与已确认期限一并失效。

## 2. 期限规则与日历

- `DeadlineRule` 明确记录规则版本、适用送达方式、天数、自然日/工作日、起算日是否计入、届满遇非工作日如何调整、精确规则定位、官方 HTTPS 快照 URL 和内容哈希。
- `HolidayCalendar` 亦有版本、地域、非工作日、调休工作日、官方快照和律师批准。系统不按本机日历、模型记忆或“通常做法”推断节假日。
- 规则与日历各自需要可核验的官方来源快照及记录中的有效许可，再经承办律师批准。合成 Alpha 的测试来源不构成真实法规或法院规则。

## 3. 期限状态与交付边界

1. 满足已确认送达日期、已批准规则和日历后，系统生成 `DeadlineCandidate`，其状态仍为“候选”；
2. 承办律师核验本案适用规则、起算、届满、顺延、地域和时区后，才能确认该候选；
3. 只有确认后的期限可进入程序事项正式快照；候选不得作为可依赖倒计时、对外承诺或法院提交材料依据。

当前实现使用显式的 `Asia/Shanghai` 等时区标签、工作日/自然日计算与版本指纹，但未接入真实法院规则库、官方节假日快照或提醒/日历服务。这些连接必须在本机安全、来源许可、持久审计和律师验收完成后再开放。
