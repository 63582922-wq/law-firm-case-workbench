# 律所案件 AI 工作台（自托管 Web）

这是中文优先、浏览器优先的律师工作台前端。主交付形态是律所受管服务器上的 Web 服务，Windows、macOS 和 Linux 律师电脑均通过浏览器使用；不是 macOS 专属客户端。

浏览器版主流程已接通服务端登录、案件权限、PDF 材料接收、页级证据审阅和案件要点只读核对。未连接这些受管服务时，浏览器版会明确显示部署门，不展示或伪造任何演示案件。

## 当前可用范围

- 服务端身份和案件权限接通前，浏览器版不加载合成案例。
- Web 端支持多文件、拖放、PDF 逐份接收和 ZIP 材料包接收；Chrome/Edge 另提供材料文件夹选择增强，浏览器永不提交或保存本机绝对路径。ZIP 由服务端先做路径、符号链接、加密、重复文件名、解压大小、压缩比、CRC 和哈希校验，回执明确为“已安全接收，待后台逐文件处理”，不会冒充已完成 PDF 入卷。可恢复分片和 ZIP 子文件 Worker 仍待补齐。
- PDF 审阅采用服务端生成的单页预览、归一化红框、锁定清单和受控生成任务，不直接把原始 PDF 嵌入页面。
- 案件要点页从同案服务端台账读取事实、诉请、争点和收付款；主办律师可确认事实、诉请范围和收付款，候选内容不会自动变成正式法律结论。
- 法律与利息页可读取同案已登记的官方法源、规则版本和法律事件，并提供受前置条件控制的确定性测算入口；适用规则、起算日和利息金额不会由浏览器或模型自行推定。
- 应诉材料页可读取同案提交台账的文书、材料包和导出核验状态；具备复核角色时可批准候选文书，主办律师可在服务端前置条件满足后锁定材料包；尚未完成独立核验时不显示法院提交下载。PDF/ZIP 接收结果不明时可按服务器编号刷新核验，不提供盲目重传。
- 既有中文办案界面、证据/利息/法源内核及受控 Agent 边界会逐步迁入同源 Web 会话；模型密钥只在服务器端配置。

## 明确不做的事

- 不提供法律意见、利息计算结论或自动诉讼策略。
- 不自动删除疑似重复证据，不将识别结果视为人工审核。
- 不生成可提交法院的文件；导出按钮在未完成核验和审批时保持禁用。
- 不以合成案例冒充可使用的律所案件。

## 律师服务与离线开发

律所管理员从仓库根目录准备并启动完整受管服务：

```bash
python3 scripts/manage_managed_web.py init
python3 scripts/manage_managed_web.py preflight
python3 scripts/manage_managed_web.py start
```

仅验证基础材料流程时，开发人员可启动离线开发模式：

```bash
python3 scripts/start_local_web.py
```

以启动器打印的地址为准（默认从 `http://127.0.0.1:33000` 开始选择空闲端口）。该模式不是完整本机工作台，不得作为律师商用交付。

仅在前端开发、且另有 API 已启动时才单独运行：

```bash
pnpm dev
```

生产部署说明将位于 [`../docs/WEB_DEPLOYMENT.md`](../docs/WEB_DEPLOYMENT.md)。旧桌面命令和 Tauri 文档仅用于历史实现参考，不是浏览器版安装步骤。
