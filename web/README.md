# 律所案件 AI 工作台（内部合成 Alpha）

这是中文优先的 Web 工作台前端。当前实现的是可运行的合成界面，不接收、上传、存储或处理真实案件材料。

## 当前可用范围

- 案件总览：显示下一项律师决定、证据范围、金额快照和只读模拟审计记录。
- 证据核验台：显示原始影像与衍生提交材料的边界、红框定位坐标、疑似重复页的人工决定和模拟审计反馈。
- 中文与币种：界面固定使用简体中文；合成金额同时显示人民币符号与 CNY，避免币种含混。
- 桌面连接：Tauri 壳只暴露一个受控的“选择本案文件夹”命令；选择后仍须在工作台确认范围，才会获得短时只读授权。

## 明确不做的事

- 不提供法律意见、利息计算结论或自动诉讼策略。
- 不自动删除疑似重复证据，不将识别结果视为人工审核。
- 不生成可提交法院的文件；导出按钮在未完成核验和审批时保持禁用。
- 不使用真实个人、法院、交易或案件数据。

## 本地运行

```bash
pnpm dev
```

再访问 `http://localhost:3000`。

桌面开发模式：

```bash
pnpm desktop:dev
```

桌面生产构建：

```bash
pnpm desktop:build
```

生产桌面构建使用 Next.js 静态导出，不在应用内嵌入 Next.js 服务器。案件写操作仍只允许访问本机 loopback API。

## 下一步接入条件

真实案件接入前，必须完成权限模型、真实 OS 身份与 Keychain 密钥生命周期、可验证审计、原件与衍生件关联、锁定版本、人工审批以及真实场景验收；这些不是桌面壳或界面演示可以替代的。
