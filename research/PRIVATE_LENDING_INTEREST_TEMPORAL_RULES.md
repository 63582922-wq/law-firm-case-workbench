# 民间借贷利息时点规则研究底稿

状态：`官方来源发现已核对；尚未制作加密法源快照，尚未由执业律师批准为正式规则`

核对日期：`2026-08-10`

本文件用于定义产品应当呈现哪些候选路径和阻断项，不是对任何真实案件的法律意见。正式计算必须引用本机加密、哈希绑定并经律师批准的法源快照与案件事件。

## 已由官方文本确认的规则

1. 《民法典》第六百七十九条规定，自然人之间的借款合同在贷款人提供借款时成立；第六百八十条规定禁止高利放贷，且自然人之间借款未约定或约定不明利息时，不能直接产生借期内利息。官方来源：国家法律法规数据库《中华人民共和国民法典》。
2. 现行民间借贷司法解释第二十五条规定，约定利率的司法保护上限以**合同成立时**一年期 LPR 四倍为锚点；一年期 LPR 指全国银行间同业拆借中心自 2019-08-20 起每月发布的数据。
3. 同一解释第三十一条对旧合同另设过渡路径：对 2020-08-20 之后新受理的一审案件，如果借贷合同成立于 2020-08-20 之前：
   - 合同成立至 2020-08-19 的部分，在当事人提出相应请求时，可适用当时司法解释；
   - 2020-08-20 至借款返还之日的部分，适用**起诉时**该规定的利率保护标准。
4. 因此产品不能把所有案件统一写成“合同成立时 LPR 四倍”，也不能把 2020-08-20 之后的上限按每月新 LPR 自动滚动。至少必须先判断一审受理时点、合同成立时点、计息区间和起诉时一年期 LPR。
5. 2015 年版本司法解释对未付利息使用年利率 24% 的司法保护线，并对已经自愿支付的 24%—36% 区间和超过 36% 的部分作不同处理。2020 年第二次修正后的过渡条款是否、以及如何作用于个案已经支付的历史利息，必须单列为律师判断，不能只按“当前四倍 LPR”机械回算。
6. 每笔付款是否属于利息、本金、费用或未指定还款，以及超过司法保护范围的已付款应返还还是冲抵本金，均会改变后续本金。产品只有在付款性质与冲抵顺序获批后，才能让下一期间按递减后的本金继续计息。

## 产品必须收集的事件

| 事件 | 为什么必须 | 缺失时处理 |
| --- | --- | --- |
| 实际出借日 | 自然人借款合同成立及本金起点候选 | 阻断正式规则包 |
| 借条/补充协议日 | 可能影响书面约定、结算和新债权凭证 | 与实际出借日并列，不自动替代 |
| 每笔付款日、金额和币种 | 决定利息/本金冲抵及后续本金 | 付款不进入正式计算 |
| 付款性质与同日顺序 | 决定先息后本、仅息或仅本 | 保留候选，阻断正式计算 |
| 一审受理日 | 决定是否进入 2020-08-20 过渡条款 | 阻断时态规则选择 |
| 起诉日 | 旧合同 2020-08-20 后期间的 LPR 锚点候选 | 不得用当前 LPR 代替 |
| 合同成立时 LPR | 新合同或特定条款的四倍上限基数 | 必须来自官方历史数据快照 |
| 起诉时 LPR | 旧合同过渡期间的四倍上限基数 | 必须来自官方历史数据快照 |

## 当前实现对应

- `official_legal_source_snapshots` 保存官方响应原字节的加密对象位置、SHA-256、条款定位、抓取时间、核验人和许可状态；
- `legal_rule_versions` 只允许 `FIXED_ANNUAL_RATE`、`LPR_MULTIPLE` 或 `NO_INTEREST`；`LPR_MULTIPLE` 必须分别绑定证明倍数公式的法律依据快照和证明具体基准值的 `OFFICIAL_RATE_DATA` 快照，LPR 四倍由服务器以基准值乘数计算；
- `case_legal_events` 保存本案经证据支持且由律师批准的触发日期；
- `case_legal_fact_bindings` 要求规则事实条件绑定到同案、已有证据且由律师确认为 `CONFIRMED` 的事实；
- `case_legal_bundle_segments` 只引用已批准规则版本、两类来源快照、事实条件和事件，年利率由服务器取值；
- 正式计算 API 不接收浏览器提交的规则段或年利率，只读取当前案件法律规则包。
- `official_source_capture.py` 已实现真实 TLS、公网对端、域名/类型/大小门禁和响应原字节加密捕获；`legal_provision_parser.py` 已对最高法第二次修正第 25/31 条、第一次修正第 26/32 条和《民法典》第 679/680 条完成真实网页解析，对 2015 原始第 26/31 条完成合成金标准解析；`lpr_source_parser.py` 已对中国货币网官方 JSON 完成 12 条真实数据解析。所有产物仍是 `HUMAN_REVIEW_REQUIRED`，不自动进入规则包。
