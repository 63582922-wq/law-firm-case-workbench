# ADR-0126：来源绑定的问题发现候选进入同一独立复核门

状态：`Accepted`

日期：`2026-09-11`

## 问题

ADR-0124 已定义“没有正式争点时”的来源绑定问题发现候选及其严格解析器，但运行级独立复核器只登记了传统律师决策包的 JSON 架构。结果是模型结果即使已经由发现候选解析器接受，运行仍在格式复核阶段失败，律师无法查看候选。

## 决策

`LAWYER_DECISION_PACKAGE_CANDIDATE` 的独立复核策略同时允许：

- 传统的 `case-agent-lawyer-decision-package-v3`；
- `agent-discovered-lawyer-analysis-candidate-v1`。

两个架构仍共享相同的候选只读标记、来源范围一致性、受控对象存储、运行图验证和律师审阅要求。发现候选必须继续通过其自身的严格解析与来源引用核验；这不是放宽通用 JSON 接收规则。

## 后果

首次研判可在真正的运行闭环中将“问题、风险、补证和下一步”交给律师查看。它仍不是正式争点、事实、诉请、法律结论、文书或对外提交材料。
