# ADR-0042：律师决策包结构化输出取消截断参数并按模型上限预检费用

- 状态：已采纳，运行验证待完成
- 日期：2026-08-26
- 关联：ADR-0041 工具支撑的律师案件决策包

## 背景

完整律师决策包调用先后两次因输出达到 7,000 token 上限而截断。此后模型职责已压缩为 `golden-lawyer-analysis-core-v2`：8 个争点及举证责任、4 个对抗分析、2 套策略、6 个补证问题和 3 个律师决定理由；风险投影、期限动作、登记选项、文书章节和全部金额由代码生成。紧凑输入控制估算为 19,952 个字符，不含四情景金额，但唯一新鲜调用仍在 4,000 token 处以 `finish_reason=length` 终止。

阿里云百炼官方结构化输出文档明确提示，结构化输出不应设置 `max_tokens`，因为它可能在 JSON 完成前截断响应。`qwen3-vl-plus` 支持 JSON Object 结构化输出，官方最大输出长度为 32,768 token；严格 JSON Schema 当前仅支持部分 Qwen3.7/3.8 文本模型，不支持本调用当前使用的 `qwen3-vl-plus`。

## 决策

1. 当前紧凑验收在第一次失败后停止，不追加外部调用，也不把缓存恢复候选记为新鲜成功。
2. `lawyer_package` 模式继续使用 `golden-lawyer-analysis-core-v2`；模型仍须真实完成争点、举证责任、攻防、策略、问题和决定理由，代码只生成重复且可确定的外壳。
3. `lawyer_package` 请求不再发送 `max_tokens`；其他历史实验模式保留原上限，以维持可复现实验行为。
4. 取消截断参数不取消费用控制。预检按 `qwen3-vl-plus` 官方 32,768 token 最大输出长度和输入所在价格层计算最坏费用；单次预算硬上限为 0.40 元，不能容纳最坏费用时请求不得发出。
5. 返回后继续执行更严格的应用层边界：核心 JSON 不超过 12,000 字符；8/4/2/6/3 数量必须精确；来源、法源、情景和决定必须命中白名单；模型不得复制正式金额、批准事实或立场、锁包或提交。
6. 修正后的代码只标记为 `IMPLEMENTED_NOT_RUN`。下一次必须是新的独立验收，不是本次失败的自动重试。
7. 如果无截断参数后仍不能形成合格核心，才另行评估迁移到支持严格 JSON Schema 的 Qwen3.7 Plus/Flash；模型切换、价格和数据路径必须另作决策，不能在失败后静默替换。

## 后果

- 最坏单次费用上限由 0.20 元提高到 0.40 元，但仍低于代码硬门且只有一次调用。
- 模型可能返回超过应用层 12,000 字符的完整 JSON；此时会形成可审计回执但内容验收失败，不会自动重写或重试。
- 当前新鲜 Agent 端到端能力仍为 `FAIL`；35 项本地测试只证明调用合同和展开器实现正确，不证明供应商真实返回已通过。
