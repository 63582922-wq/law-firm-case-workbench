# ADR-0027：以代码总控和隔离执行平面构建律师 Agent OS

- 状态：已采纳
- 日期：2026-08-13
- 关联：ADR-0026 浏览器优先的自托管律师工作台

## 背景

项目已经分别形成材料上传、证据页、法律/计算/文书台账、若干 Worker、Skill Registry、材料模型候选和动态办案计划。这些能力仍是分散的功能链：没有一个能够接收律师目标、持续观察案件、生成任务图、调度工具、读取结果、重规划、恢复并交付成果的统一总控。继续逐项增加“AI 功能”会得到更多按钮，而不是产品级智能体。

同时，律师希望 Agent 能处理常见文件和图片、联网检索并执行命令。直接把宿主 Shell、服务器文件系统或任意网络交给模型，会破坏案件隔离、密钥边界、证据完整性和律所保密义务。

## 决定

采用 **一个代码 Agent Control Plane + 多个受限模型/Skill/Worker + 每任务隔离沙箱** 的架构：

1. 代码总控持久化目标、案件快照、计划 DAG、任务状态、依赖、预算、审批、工具回执、检查点和重规划事件；模型不能直接修改状态机。
2. 模型只能生成严格结构化的候选计划、抽取、研究摘要和草稿；Plan Compiler 将候选与当前可执行 Skill、权限、来源、预算和审批门相交后才产生任务。
3. 通用文件能力由文件注册表和版本化解析器扩展；未知、加密、可执行或高风险文件进入隔离/异常队列，不因“任意文件”承诺而盲目执行。
4. 命令只在 rootless、一次性、默认断网、无服务器密钥、无其他案件、资源受限的沙箱中运行。模型不获得宿主 Shell；常规模式只允许签名工具模板，高级脚本模式仍受同一沙箱和策略检查。
5. 联网只通过受控搜索/浏览和出站代理，查询先脱敏；正式法源保留官方来源、时态、快照和引用回执。网页内容永远作为不可信数据。
6. 记忆分为工作/运行、案件、律师个人、律所和公共法源层。跨案知识必须先脱敏、审批和发布；RAG 在召回前执行权限、保密、时效和来源等级过滤。
7. 低风险、可逆内部任务可在预算内连续执行；正式事实、法律口径、计算参数、立场文书、案卷外发和最终导出保留律师门；自动对外提交、签章、发函、付款和删除原件禁止。
8. 律师前台围绕目标、进度、决定、来源和成果组织，不以聊天、固定流程或逐页人工按钮作为主产品。

### 命令执行适配器的首个落地边界

首个执行适配器采用 rootless Podman，一次任务对应一个一次性容器。它只接受由已登记模板和 `SandboxTaskGrant` 编译出的 `StructuredSandboxCommand`，不提供 Shell 字符串、宿主路径、环境变量或任意镜像入口。启动前必须同时验证：总控 `RuntimeAdapterManifest` 与当前沙箱策略摘要一致、Podman 确为 rootless、镜像本地检查结果与固定 digest 一致、部署签名验证器返回同一 digest 和签名策略回执。

容器固定使用只读根文件系统、非 root 身份、`network=none`、关闭代理继承和容器日志、丢弃全部 capabilities、`no-new-privileges`、私有 PID/IPC/UTS、进程/内存/CPU/时间/输出上限；只挂载本次已核验的只读案件输入和独立 `0700` 输出目录，不能挂载 Docker/Podman socket、其他案卷或服务器密钥。授权联网仍由独立 HTTPS Broker/Connector 执行，当前命令容器不会把“已授权外网”转换成直接网络。

任务结束后，Worker 必须确认容器已清理，逐个验证输出为普通单链接文件、计算哈希、执行恶意文件扫描、再由对象存储适配器原子登记；最终回执必须重新通过 `verify_sandbox_receipt`。无法确认进程退出、清理、扫描、登记或回执一致性时保守失败，不能发布派生成果。

这只是可部署执行适配器及其契约测试，不代表当前机器已经安装或生产部署了 rootless Podman、签名基础设施、扫描器和私有对象存储。只有生产预检和隔离验收留下真实证据后，相关 Skill 才可从 GATED 转为 IMPLEMENTED。

详细能力和验收基线见 `docs/LAWYER_AGENT_OS_ARCHITECTURE.md`。

## 后果

- 现有材料 Agent、代理档案和动态计划只有接入统一总控后才能宣称产品可用；
- Skill Registry 的成熟度必须由真实运行时适配器和启动预检决定；
- 需要新增持久 Agent goal/run/task/event/checkpoint/approval/artifact 领域及独立 Worker；
- 需要为命令沙箱、网络出站、文件类型、记忆/RAG、提示注入和跨租户建立独立测试与运维证据；
- 这增加了基础设施和实现成本，但避免用无限权限换取表面上的“像 Agent”。
