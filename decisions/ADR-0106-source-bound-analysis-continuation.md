# ADR-0106：读卷完成后的同任务分析续阶段

状态：Accepted（实施与合成验收中，非商用放行）

读取/抽取阶段完成后，原material_stage限制继续生效，导致已提取材料不能自然进入分析。
不能新建Run清零费用、伪造案件变更、删除律师暂缓决定，或要求用户重新上传解决。

新增CASE_ANALYSIS_STAGE_REVIEWED事件，保留目标、旧图、成果和累计用量；只接受具有
独立验证完成抽取图的READY_FOR_REVIEW状态。事件绑定事件版本、案件快照、旧图、
所有未确认候选的内容摘要和复核身份。写入时在同一授权事务重读候选，拒绝漂移。
后续图仅允许本地案卷整理、一次律师分析，以及至多一个本地法源检索计划。
模型调用最多一次、120分，无自动重试；本地任务保留现有最多三次尝试，但受Run累计
尝试上限约束。既有范围和累计预算不清零，不批准任何事实或法律口径。

0097增加数据库事件约束、身份/版本/前置抽取/候选范围校验及现有健康控制下的队列
例外。不转移旧异常控制所有权。纯合同和真实Worker预编译通过才应用及追加事件。

110分旧占用包含抽取保守预留，不能当实际供应商账单。用户已授权必要模型调用，
这次开发不新增逐次用户确认要求；合成身份入口不代表生产自动审批或律师认可。
