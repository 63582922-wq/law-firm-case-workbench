# ADR-0021：已批准案卷范围通过逐文件安全队列进入证据原件

状态：已接受并实现第一段

## 背景

文件夹盘点只证明某时点有哪些文件，不能证明文件可安全解析，也不能让浏览器提交页数和媒体类型后直接成为证据。Word、Excel、图片和压缩包没有天然稳定的 PDF 页码；把它们一律登记为“一页”会破坏证据回链。

## 决定

1. 只有当前已批准盘点可以建立接收任务，且排队前使用仍有效的本机 grant 重新计算 Manifest；变化即停止。
2. 每个文件有独立短租约、最多三次恢复、稳定幂等键和明确终态。任务与项目状态进入 PostgreSQL、绝对路径和 grant 不进入。
3. SYSTEM_WORKER 仍不能任意读取文件夹；实际源文件必须由原批准人的 OS 绑定 grant 按相对路径解析并重验哈希。
4. 本机恶意文件扫描结果及扫描器/病毒库版本是登记前置条件，不可用时 fail closed，不调用联网服务替代。
5. 第一段只自动登记通过静态结构检查的 PDF。其他格式进入转换/人工处理，活动、加密、损坏或感染文件进入阻断；不伪造页数。
6. 新案卷范围获批会使旧接收任务失效，但不删除任何已登记原件。

## 后果

证据台账得到的页数来自确定性 PDF 解析而非浏览器或模型；代价是桌面包必须运营本机扫描器，并继续实现其他格式的隔离转换和授权恢复。队列已真实持久化，但在生产 Worker、扫描器和实库未配置时只应显示为等待，不得声称材料已处理完成。
