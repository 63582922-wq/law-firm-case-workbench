# ADR-0003：采用“现代案卷室”作为中文桌面工作台主视觉

状态：`Accepted（暂定；Phase 1 真实律师可用性测试可要求修订）`

日期：`2026-08-09`

## 背景

视觉设计简报要求用相同的合成案件密度探索三种中文桌面方向：现代案卷室、证据控制台和专业合议工作室。产品负责人明确要求持续开发，并委托项目负责人完成暂定选择，不等待其个人参加视觉评审。

三套原型均已实现并在本机浏览器实际查看：

- A：`design/prototypes/modern-casefile/`；
- B：`design/prototypes/evidence-console/`；
- C：`design/prototypes/professional-studio/`。

## 决策

选择 **A「现代案卷室」** 作为正式中文桌面 Web 的主视觉语言。

1. 默认工作面使用低饱和暖白背景、深墨文字、克制分隔线和纵向阅读节奏，服务长 PDF、证据、计算表和文书审阅；
2. 首页将“下一项律师决定”、来源、影响范围和阻断原因置于最显著区域，聊天不成为主界面；
3. 证据工作台采用 A 的原件预览/页级列表/结构化说明三栏布局；原件、候选、派生件、红框和风险告警维持不同语义；
4. 吸收 B 的高密度金额、币种、来源、重复页和异常表格组件，但不把深色控制台作为默认长时间阅读背景；
5. 吸收 C 的交接责任、审批线索和风险摘要组件，但不让协作看板挤占证据与文书的主阅读面积；
6. 中文显示层遵守 `docs/CHINESE_FIRST_LANGUAGE_CONTRACT.md`；任何机器码仅在技术详情中显示。

## 原因

- 民间借贷应诉的核心高频动作是阅读、比对、确认和撰写，A 对中文长文本、PDF 页面和“只处理一个下一决定”最友好；
- 在 1440px 和 1280px 的本机浏览器查看中，A 的核心信息不发生横向溢出，证据流程可从案件总览进入页级审阅；
- B 的信息密度很强，适合交易/计算局部页面；C 的协作线索很完整，适合审批/审计局部页面；两者不适合作为整套产品的默认视觉重心。

## 后果

- Web 前端可据此建立中文 Token、案卷导航、阅读型表格、状态语义和桌面断点；
- 视觉选择不代表已由律师接受；Phase 1 的 5 人任务测试仍可要求调整视觉、文案或交互；
- 不可重新混合三套完整视觉语言，以免形成通用后台拼贴；后续组件吸收必须保持 A 的阅读优先层级。

## 被否决方案

### B「证据控制台」作为全局默认

其结构化数据表达优秀，但大面积深色和控制台密度会增加长时间中文阅读、文书编辑与复杂证据对照的疲劳。

### C「专业合议工作室」作为全局默认

其交接和责任表达优秀，但多栏常驻布局会压缩证据原页与长文书的可用宽度，并使产品更像协作项目看板。
