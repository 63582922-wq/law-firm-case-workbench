# ADR-0081：封存模型响应的独立律师复核候选

状态：`Accepted`

日期：`2026-09-05`

## 背景

M2 的唯一一次受管 `qwen3.7-plus` 调用已有完整、可认证的私有响应归档和供应商回执。该历史任务在当时的严格解释器下以
`LAWYER_ANALYSIS_OUTPUT_REJECTED` 停在 `WAITING_INPUT`；ADR-0077 和 ADR-0080 后，当前解释器可在不发出模型请求的
情况下把该封存响应解析为 `NEEDS_LAWYER_REVIEW` 决策包候选。

原有产物链只允许“任务成功 → 独立验证通过 → `case_agent_artifacts`”的正常路径。这一约束是正确的：不能为了显示一个
候选件而篡改 M2 的失败回执、把任务改成成功、补写验证通过记录，或使其进入终审、文书、锁包和法院提交路径。但完全没有
可见审阅路径同样不符合律师工作流：一个已经可认证、可重新严格解释的历史供应商响应，应能在明确边界下让有权限律师核对。

## 决策

1. 新增独立的“封存响应恢复候选”记录。它引用普通私有候选件字节，却**不**写入 `case_agent_artifacts`、Agent 事件、
   任务回执或独立验证回执；M1、M2、M3 的运行状态、事件版本、外发台账和失败原因均不可改写。
2. 恢复记录只能由专用 SYSTEM_WORKER 写入，且必须同时绑定：原运行/图/任务/输入哈希、唯一已开始的外发请求、原始
   失败回执、认证的原始响应与归档哈希、当前解释器策略哈希，以及候选件内容哈希。写入采用确定性幂等键；没有任何网络
   发送、模型调用或浏览器输入通道。
3. 恢复候选只在原运行仍处于相同图、相同快照、相同事件版本且仍为 `WAITING_INPUT` 时可被读取。任一上游状态或来源
   变化都会使它不再作为当前工作成果展示；历史记录保留用于审计。
4. 浏览器沿用既有 MFA、律所、案件角色和来源页授权门，仅展示安全投影。恢复候选还必须只投影给明确声明
   `sealed-recovery-v1` 能力的新版审阅界面；未声明该能力的旧界面只能读取普通候选。能力声明不是授权，不能绕过任何
   身份或案件范围校验；候选列表响应必须回传 `Vary: X-Lawcase-Artifact-View`，避免中间缓存混淆两种投影。
   界面必须明确标注“封存响应恢复候选”：它可供律师阅读和回链来源，但不是任务成功、正式事实、法律结论、文书、
   终审完成、锁定提交版或法院材料。
5. 终审、文书生成、文书修订、提交包和任何自动审批只读取正常已验证的 `case_agent_artifacts`。恢复候选永远不能满足
   这些前置条件。
6. 本轮只允许固定、无参数的 M2 回放写入一次恢复候选；M3 仍因无来源事实推断而不可恢复，且不得建立 M4、重发或自动重试。

## 实施证据（2026-09-05）

- `0077_sealed_response_recovery_candidates.sql` 已在本地受管环境应用，并通过运行时 PostgreSQL 权限、RLS、
  迁移和触发器预检。固定 M2 恢复命令仅执行一次，写入候选
  `fc351603-2f2f-5bc5-80ce-e8f0db43f773`；候选为 `NEEDS_LAWYER_REVIEW`，`court_ready=false`。
- 写入后只读核验显示：M2 仍为 `WAITING_INPUT`、事件版本 8；分析任务仍为 `FAILED`、尝试数 1；失败回执仍为
  `LAWYER_ANALYSIS_OUTPUT_REJECTED`；外发数仍为 1；验证回执仍为 0。没有模型调用、没有重试，也没有把该候选
  写入正常 `case_agent_artifacts`。
- 受管边缘 API 已实际验证“列出候选”和“读取候选”两个只读路径。明确声明 `sealed-recovery-v1` 的客户端得到恢复候选、
  9 个律师审阅区块及非晋升提示；未声明该能力的旧客户端只得到 1 份普通 `CANDIDATE`。该能力协商不增加任何授权。
  两种请求的列表响应均已实际返回 `Vary: X-Lawcase-Artifact-View`。此证据仅覆盖合成 loopback 认证路径，不替代真实
  OIDC/MFA 浏览器旅程、律师认可或商用放行。

## 后果

- 律师可以在受管 Web/API 审阅面核对一份来源可回链、真实模型已留痕的候选，而系统不会把“当前解释器能读懂旧响应”偷换为
  “旧任务已经成功”。
- 恢复链额外增加了独立的数据库和对象存储边界、最小权限授权、幂等性与当前性检查；这些复杂度是避免误导律师所必需的。
- 这只闭合“历史响应的安全审阅”能力。它仍不构成商用放行；正常模式的新鲜单次调用、浏览器律师旅程、律师认可和恢复
  演练仍须各自留证。
