# ADR-0101：文书执行保留当前计划授权信号

日期：2026-09-10。状态：Accepted。

实际文书运行0259d9c1-7427-5744-b1a5-4cec4b7a3291在规划阶段被拒绝，尚无任务外发。
根因是应诉分析的窄投影主动移除了ACTIVE计划信号，同时被误用于已激活计划的文书阶段。
文书阶段改用既有权威完整快照，仍由受控本地规划及严格文书编译器执行。
不得以增加模型调用或删除当前计划校验解决。初次分析保持原窄投影。
旧失败不可覆写，恢复必须走可审计命令并验证无未知结果。

0089扩展既有显式本地重发命令，仅接受一个有本地受控提案的失败规划尝试、无图、无任务、
无规划外发、无任务外发及相同当前计划。SQL守卫与Web准备/创建入口使用同一判定。
无自动循环，无模型预算增加。新执行保留前任关系，原失败事件不变。
0090明确区分提案持久化成功与随后图编译失败：要求本地提案SUCCEEDED、运行拒收，
不把已保存的提案回执伪改为失败。0089的初始状态匹配由此前向修正，其他约束不变。
