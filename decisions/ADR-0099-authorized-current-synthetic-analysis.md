# ADR-0099：现有合成案上的新授权分析

日期：2026-09-10。状态：Accepted。

用户明确要求必要模型调用直接执行，不再因旧单次验收限制停工。本次在既有M3合成案当前
版本上通过正常Web服务新建独立、固定幂等身份的分析运行，最多一次外发、120分。
不重建案卷，不重跑导入，不修改M3旧运行/外发/失败结果。任何未知结果不重发。
仅正常严格核验通过才报告分析就绪，停在律师审阅，不自动确认法律立场。

此案历史上预置过确认事实，因此这次只验证分析交付半链；不能声称已验证原始资料自主理解。
ADR-0098读卷准备及完整同目标阶段推进仍是独立未完成的开发项，不因此新调用而省略。
新授权覆盖本次新运行，不回溯改变ADR-0079/0080的历史失败和禁止自动重试。

新建入口原来将所有WAITING_INPUT永久视为活动运行，阻断已知响应拒收后的显式新请求。
现于原案件事务锁下重放不可变事件：仅当全部任务已有完整、明确的成功/失败回执，且至少
一个失败明确为LAWYER_ANALYSIS_OUTPUT_REJECTED，才允许显式新命令。UNKNOWN、运行中、
未完成任务或其他失败类型仍拒绝。新运行固定幂等键，旧状态/回执不变，不触发自动重试。
