# ADR-0131：已激活计划直接生成可复核候选

状态：`Accepted`

日期：`2026-09-11`

## 问题

主办律师已经激活动态计划后，系统仍要求对每一份纯本地、不可对外提交的候选文书再次确认。这样把“生成供复核的候选件”和“采纳法律结论或对外提交”混为一谈，导致律师无法获得本应由 Agent 自动完成的办案成果。

## 决定

- 已激活计划中精确绑定的 Word、Excel 候选生成属于 `A2_INTERNAL_REVERSIBLE`：仅可读取该计划项、写入受控派生件、无网络、无外部调用、无自动重试。
- 生成后的每份候选仍保持 `NEEDS_LAWYER_REVIEW`；不能自动采纳为正式事实或法律意见，不能锁定、下载为正式提交件或向外部发送。
- 对已经由旧策略编译、但尚未执行任何任务且无外部活动的图，允许整个计划谱系一次受控重发。旧图保留审计记录，重发只能使用同一 ACTIVE 计划、相同来源和相同成果项。

## 后果

律师只需一次“开始生成”即可得到待审候选，审核动作回到候选内容、版本和最终提交边界，而不是阻塞在生成之前。任何网络调用、模型调用、任务尝试、产物写入或外部提交一旦发生，均不能适用该恢复路径。
