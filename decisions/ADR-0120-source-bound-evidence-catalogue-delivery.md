# ADR-0120：独立证据目录只编译已确认纳入范围的证据页

状态：`Accepted`

日期：`2026-09-10`

## 问题

律师工作台此前有证据目录模板，却没有把它接入统一办案 Agent 的受控成果目录。页面若称“证据目录已
交付”，会把模板能力误述为可下载、可追溯的实际成果。反过来，若让模型根据材料自由填写证据名称、
证明目的或证据三性，又会把未审阅判断伪装成可交付内容。

## 决定

- 新增 `EVIDENCE_CATALOGUE` 为封闭的内部审阅成果种类，固定输出为 XLSX，并沿用受控 PDF 审阅稿。
- 只有律师已确认且标记为纳入范围的 `EVIDENCE_PAGE` 才可成为目录行。每行保留原文件名、页码、
渲染页哈希和来源绑定；没有已确认页时不得创建目录候选。
- 目录编译完全确定性执行，不调用模型。`拟证明事项` 固定为“待律师核对”，审阅状态固定提示三性待核对；
系统不声称真实性、关联性、合法性、充分性或证明力。
- 目录候选仍需要律师审阅、版本校验和下载回执；不得因此锁定提交材料、改变证据批准状态或授权对外提交。

## 后果

律师可以在同一成果入口取得独立、来源可回看的证据目录，而不是在研发说明中寻找模板。目录解决的是
整理与交付载体，不替代律师确定证明目的、证据三性、举证策略或法院提交决定。
