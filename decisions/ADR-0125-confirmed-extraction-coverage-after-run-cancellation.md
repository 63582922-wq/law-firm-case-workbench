# ADR-0125：律师已确认的材料提取在运行取消后仍保持页面覆盖

状态：`Accepted`

日期：`2026-09-11`

## 问题

ADR-0114 正确地规定：被取消的运行不能让未完成的材料核对看起来已经完成。ADR-0117 又规定，同一运行在案件快照更新后不能遗忘已经验证的页面提取。

但两者结合后仍有一个断点：如果提取结果已通过独立验证、已进入律师可见的批次、并且律师已确认其候选成为正式账本对象，随后为了停止旧的整案计划而取消运行，覆盖查询会重新把相同原始页排入提取。这既浪费受限调用额度，也使已确认事实的后续研判无法启动。

## 决策

页面在被取消运行中仍可视为已处理，必须同时满足：

- 提取任务尝试成功，任务图已独立验证，且运行未失效；
- 该任务的私有提取批次存在；
- 同一批次存在不可变的律师批量确认回执；
- 覆盖仍严格绑定同一事务所、案件、运行、图、任务及原始页面引用。

只有“已取消但没有律师确认”的批次仍不算覆盖，继续适用 ADR-0114，下一轮必须重新建立可操作的材料核对。

## 后果

取消过时的整案计划不会撤销已由律师确认的材料处理成果；后续运行可以直接进入来源绑定研判。该规则不把候选自动提升为事实，也不把未确认、失败、未知或失效的模型输出视为已处理。
