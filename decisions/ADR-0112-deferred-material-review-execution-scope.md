# ADR-0112：暂缓材料核对不冻结来源受控研判

## 背景

“暂缓核对”用于保留尚未确认的提取候选及律师说明。它不是已确认事实、不是补证缺口，也不是待重提取任务。此前调度器把所有活动后续事项一律视为案件级执行锁，导致律师即使明确将候选排除在研判前提之外，也无法重新启动风险研判或生成答辩初稿。

## 决策

- `DEFERRED_REVIEW` 继续保留在材料复核链，继续显示为待律师处理，不进入模型输入、正式事实、金额计算或提交文件。
- 只有活动中的 `REEXTRACTION` 与 `MORE_EVIDENCE` 继续阻止不相关运行；它们分别意味着原始材料需重取或必要来源尚缺。
- 只重新唤醒从未离开 `RUN_CREATED` 的非恢复、非控制运行；Worker 领取时仍再次执行同一防护条件。
- 旧的未知响应不重发、不覆盖；本决策仅允许一项新的、已限定来源的运行开始本地规划。

## 验收

- 有活动 `DEFERRED_REVIEW` 的案件可进入新运行的本地规划，但候选仍不出现在初次研判输入中。
- 有活动 `REEXTRACTION` 或 `MORE_EVIDENCE` 时运行继续被阻止。
- 恢复控制运行、已取消运行、已执行运行不因本次迁移被重新排队。
