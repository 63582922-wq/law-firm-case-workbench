# ADR-0087: 既有迁移的受限所有者 DDL 窗口

状态：接受；2026-09-05。

原生 PostgreSQL 16 空库执行证明：0064 在显式切换至 ledger confirmation owner 后
重建函数失败，因为前序迁移已撤销该角色的 public CREATE。0066、0067 使用相同模式。
不改写可能已经应用的迁移，也不将业务运行身份提升为超级用户。

部署入口仅在执行 64、66、67 前临时授予该 NOLOGIN 所有者 schema CREATE，每个文件后
立即撤销；失败退出的管理窗口清理也撤销。仍保留原文件摘要与 APPLYING 现场，不自动重放。
空库检查读取部署入口同一允许清单，并检查最终撤权。不以语法或模拟测试代替真实迁移。

硬终止可能跳过清理：既有迁移管理窗口仅允许停机维护，不得同时运行应用；重新启动业务前
必须检查 APPLYING 和角色权限、完成原有 post-migrate-hardening。此变更不授权生产部署。
