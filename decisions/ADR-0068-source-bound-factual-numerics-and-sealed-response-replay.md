# ADR-0068：来源绑定的事实数字与封存响应离线回放

- 状态：已采纳，离线复验待完成
- 日期：2026-09-04
- 关联：ADR-0041、ADR-0043、ADR-0044、ADR-0055、ADR-0067

## 背景

ADR-0044 为避免模型自行计算正式金额、利率和期限，曾把律师分析自由文本中的任何阿拉伯数字、
全角数字、货币符号和百分号一律拒绝。该规则安全但过宽：受管 v3 的唯一真实响应没有计算、批准、
锁定或外发声明，却在待律师复核的风险分析中原样提到服务器投影已有的诉请金额、银行流水金额、
付款金额、日期和原币种。因此响应被 `LAWYER_ANALYSIS_OUTPUT_REJECTED` 拦截。

一刀切禁止数字会迫使 Agent 回避律师最需要核对的“哪一笔、哪一天、哪一个金额”的事实差异；
而放开自由数字又会重新允许模型制造金额、汇率、比例、计算结果或法律后果。两者不能混为一谈。

v3 的外发记录、原始响应、失败事件和 `WAITING_INPUT` 状态已经是不可变审计事实。它不能因为
新解释器通过而改记为成功，也不得重新外发。

## 决策

1. 区分“来源绑定的事实数字”与“模型生成的正式数字结果”。模型只能在待律师复核的分析文字中
   原样复述服务器当前投影里已有的日期、金额和币种事实；不得创设、补齐、转换或计算任何数字。
2. 每次分析合同由代码从 `BoundCaseContextProjection` 的 `primary_text` 与 `secondary_text` 建立
   规范化数字索引。模型文本中的每一个数字事实必须同时满足：
   - 可规范化匹配至少一个服务器投影中的同一日期、金额和币种事实；
   - 落在该文本字段允许引用的来源集合内；
   - 在候选包中形成路径、原文字面量、规范化值和精确 `source_ref` 的来源绑定记录。
   编号列表的纯排版序号不是案件数字，不计入该规则。
3. 下列内容继续失败关闭，即使某个数字恰好在来源中出现：计算式、加减乘除或等式、百分比、
   货币符号、汇率换算、合计/差额/抵扣后的新数值、正式利率或期限、以及事实确认、法律结论、
   批准、锁定、发送或法院提交声明。正式金额、利率、期限和情景结果仍只能由版本化确定性工具
   生成并独立复算。
4. 新生成的律师决策包升级为带 `numeric_fact_bindings` 的版本化候选格式。独立解析器必须重新从
   `source_catalog` 计算允许数字并核对每条绑定；旧格式仍按原来的无数字规则读取，不因新规则被
   宽松解释。
5. 封存 v3 响应只允许在不调用供应商、不发送供应商请求、不写入案件、运行、审计或对象存储的
   回放路径上重新解析、编译和渲染；只可经认证读取既有私有响应归档。回放结果是“当前解释器对历史封存响应的离线证据”，不是
   对 v3 历史运行的状态修改，也不是一次新的 Agent 运行。
6. 本决策不授权创建 v4 或任何新的模型调用。若封存响应仍不能通过来源、语义、编译或渲染门，
   只交付阻断证据并重新评估架构。

## 后果

- 律师能看到“诉请金额与流水金额是否一致、哪笔付款是否关联、日期和原币种何在”等可审阅
  的事实差异，而不是被迫从无数字的泛化描述反向查找。
- 每个保留的事实数字都有稳定来源版本和机器可复核的绑定；模型仍没有正式金额、规则、批准
  或提交权限。
- 这只修正内容合同和候选审计格式。浏览器律师旅程、真实律师认可、锁定提交包、跨租户、
  备份恢复和商用发布仍是独立门槛。
