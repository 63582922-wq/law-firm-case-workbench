# ADR-0046：已核验来源上的确定性文书版本链

- 状态：已采纳，实现中
- 日期：2026-08-29
- 关联：ADR-0027、ADR-0040、ADR-0041、ADR-0044

## 背景

Agent 首次执行形成的结构化候选、可编辑 Office 文件和 PDF 审阅稿是不可变成果，并且与
当时安装的模板版本、来源集合、案件快照和独立核验回执精确绑定。模板在律师审阅前可能因
排版缺陷、中文可读性或律师决策表达改进而前向升级。覆盖旧对象、改写数据库哈希或重新运行
已经成功的 Agent 任务都会破坏审计链；为了取得新版式而再次调用规划或分析模型，也会增加
不必要的费用、数据外发和不确定恢复风险。

系统需要在不改变原 Agent 成果、不新增模型调用的前提下，从同一份仍然有效的已核验来源
生成一个新的、可独立核验的律师审阅版本。

## 决策

1. 原 Agent 文书包永久保留。模板升级只允许追加 `DETERMINISTIC_TEMPLATE_REVISION`
   版本；每个版本记录根文书包、直接前序版本、连续版本号、模板 ID/版本/哈希、请求人、
   执行 Worker、独立验证 Worker 和三件套对象回执。
2. 浏览器只能对当前 Agent 图中已通过独立核验、仍处于 `READY_FOR_REVIEW` 且尚未完成
   律师终审的文书根包请求更新。浏览器不能提交模板、来源、正文、文件路径、模型、工具或
   对象键，只能提交它已看到的版本号和幂等请求键。
3. 更新命令进入持久任务箱。执行 Worker 从服务器模板注册表选择当前模板，在同一案件版本
   上重新读取当前活动计划、代理情境、权威来源和已验证律师决策包；任一来源、计划、代理
   情境、案件版本或前序版本漂移即失败关闭。
4. 新版本只运行确定性候选编译、Office 生成和隔离 PDF 渲染；网络策略为 `DENY`，模型调用、
   外部调用和费用均固定为零。渲染结果未知不自动重发，保留可恢复状态。
5. 新三件套仍为 `NEEDS_LAWYER_REVIEW`，不得写入正式事实、法律结论、金额计算、审批或法院
   提交状态。独立验证 Worker 必须重新读取私有对象，复核哈希、格式、来源清单、模板和版本
   链后，追加成功回执；没有成功回执的新版本不进入律师阅读面。
6. 同一根文书包只允许一条**已通过独立复核**的线性版本链。请求使用乐观并发、根包事务锁
   和幂等键；并发请求只能有一个基于当前前序版本成功，旧版本号请求返回冲突，不自动转用
   更新后的前序版本。已生成但复核为 `FAILED`/`UNKNOWN` 的候选包作为旁路审计尝试永久保留，
   不占用已验证链位置；该终态落库后，律师可以基于同一已验证前序版本建立新的显式请求。
7. 律师阅读页默认展示最新已独立核验版本，同时明确版本号、模板版本和更新状态；历史版本
   仍可追溯，但不能伪装成当前版本。最终 Agent 终审必须重新打开并下载当前版本。

## 后果

- 模板和排版缺陷可以前向修复，而不篡改旧成果或重复调用模型。
- “Agent 已成功”与“当前文书模板可交付”成为两个可审计但连续的状态；最终终审只接受当前
  已验证版本。
- 新增持久命令、Worker 处理、版本链和独立验证回执，需要数据库迁移、运行时预检、Web 状态
  投影以及用户视角端到端测试共同完成；仅有代码或离线测试不能宣称商用可用。
