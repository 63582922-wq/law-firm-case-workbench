# ADR-0057：官方法源回退来源与媒介类型一致性

- 状态：已采纳
- 日期：2026-09-04
- 关联：ADR-0045、ADR-0054、ADR-0055

## 背景

被告应诉的单次真实验收需要先把《中华人民共和国民法典》第六百七十九条、
第六百八十条的原文作为可追溯输入接入。国家法律法规数据库的既有 PDF 是首选
来源，但在本次受管验收时钟下其 TLS 证书已过期，必须失败关闭。此前登记的最高
人民法院网页回退地址当前返回 403，不能把历史探测结果当成今天可用的运行事实。

《KNOWLEDGE_AND_SKILLS.md》已将最高人民检察院列为一级正式法律依据来源。其
官网 `https://www.spp.gov.cn/zdgz/202006/t20200602_463886.shtml` 经本次直接、
证书校验的 HTTPS 探测返回 200、`text/html`，且包含上述条文。它是官方公开的
法律文本镜像，不改变法律的发布机关或效力层级。

同时，验收脚本曾将已按 `text/html` 存储的对象登记为 `application/pdf`。这种
媒介类型不一致会破坏私有对象回读与法源账本之间的可验证契约，不能以“内容能看”
为由容忍。

## 决策

1. 保留国家法律法规数据库为 `CN-CIVIL-CODE-680` 的首选发现来源；将最高人民
   检察院的上述精确 HTTPS 页面登记为当前可执行回退来源，并且只增加
   `www.spp.gov.cn` 这一最小域名白名单。
2. 受管验收只接受该精确 URL、无跳转、TLS 校验成功、HTTP 200、`text/html`、
   UTF-8 和三个固定条文标记。任一条件不满足就在模型调用前停止；不得改用不安全
   TLS、搜索摘要、模型记忆或未登记镜像。
3. 私有对象存储收据、法源账本的 `content_media_type` 与实际受控响应必须完全
   一致。验收运行记录为“最高人民检察院官网公开文本”，仍以
   `PRIMARY_LAW` 表示所载法律的效力类型，而不据此产生本案法律结论。
4. 这项回退只服务于受控来源绑定，不把发现注册表自动升级为可进入法院提交包的
   正式法源，也不替代律师复核、版本效力检查或完整的官方法源捕获/审核工作流。

## 后果

- 首次真实验收不再依赖一个证书失效或当前不可访问的页面，同时保持精确来源、
  最小白名单和可重现的字节哈希。
- 媒介类型错配会在写入前被修复，而不是在文书链后段才暴露为不可读或不可审计。
- 最高人民检察院页面是一级官方公开来源中的回退，不是国家法律法规数据库的替代
  发布机关；面向真实案件的法源捕获、审查与律师批准仍需按 ADR-0045 独立完成。
