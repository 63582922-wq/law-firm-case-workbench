# ADR-0122：网页端以固定官方来源目录驱动依据核验

状态：`Accepted`

日期：`2026-09-11`

## 问题

律师网页已能展示已登记的依据和规则，但不能把已确认的诉请、争点转化为一条可操作的“补齐官方依据”
路径。现有官方原文保存、解析、人工复核和登记能力仍只由旧本机入口调用，导致网页主线在“依据与测算”
处没有下一步。

## 拟议决策

- 网页仅展示服务器维护的、与首版民间借贷场景有关的官方来源目录。浏览器只提交目录项和案件版本；
  目标网址、查询摘要、响应字节上限和授权哈希均由服务器固定生成。
- 每次点击仅创建一项、十五分钟内有效的公开原文保存任务。请求不携带案卷正文、当事人信息、浏览器登录信息
  或模型凭据；后台只使用无凭据 HTTPS 读取所列官方网站。
- 读取结果先停在“待律师核对”。律师确认来源定位后，才可以登记为本案官方依据；规则版本、适用期间和
  金额参数继续按既有独立审批流程办理。
- 将抓取工作接入现有单例案件 Worker 的有界辅助周期，一次最多处理一项已授权任务；没有授权时不发网，
  不新建常驻进程，也不影响模型任务的预算或状态。
- 生产对象保存继续按律所和案件范围绑定，抓取解析与后续登记必须对同一私有对象的内容哈希进行复核。

## 落地证据

- 网页端已提供“加入核对、查看官方原文、填写律师核对定位、登记本案依据”的连续动作；不会向浏览器
  返回目标地址、查询摘要、哈希、对象定位或模型/Worker 信息。
- 已实现按律所和案件范围绑定的 S3 抓取对象适配器。写入结果不明时仅按同一内容哈希、媒体类型、律所和
  案件进行只读恢复，绝不覆盖或枚举对象。
- 官方来源抓取接入既有单例案件 Worker，每轮最多处理一项，并且不含模型调用。2026-09-11 已用全合成
  案件实测读取最高人民法院公开的民间借贷司法解释文本，完成解析、律师核对模拟和本案依据登记。
- 单元回归覆盖固定目录、浏览器不能注入 URL/查询/哈希、对象跨案件隔离、写入不明恢复、单项 Worker
  周期和律师核对/登记的服务器端哈希绑定。
