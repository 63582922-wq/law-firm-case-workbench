# ADR-0071：模型未绑定差额数字的来源派生脱敏降级

- 状态：已采纳，待离线回放复核
- 日期：2026-09-04
- 关联：ADR-0043、ADR-0044、ADR-0068、ADR-0069

## 背景

固定 V4 合成验收的唯一真实模型响应结构、来源枚举、攻防、策略、安全字段和全部已绑定数字均有效，
但在两处自由文本中把“诉请金额”与“流水金额”相减后写出了一个未在服务器投影中出现的差额数字。
该数字恰好可以由同一字段已引用的两个来源复算，但它仍是模型自行计算的结果；原有硬门把运行
停在 `WAITING_INPUT` 是正确的。

直接允许该数字会把模型计算重新带入律师成果。继续把整份响应全部丢弃，则会让一个可以安全降级、
可由来源复核的分析失去律师审阅价值。两者之间需要一个不改变原始响应、也不把模型数字提升为
案件事实或正式金额的窄通道。

## 决策

1. 原始供应商响应始终按原字节、原哈希私有留存；模型输出本身仍不得包含未绑定数字。该策略不是
   放宽模型数字权限，也不得把 V4 的历史失败状态改记为成功。
2. 仅在下列全部条件同时成立时，解释器才可把一个未绑定金额字面量从**待律师复核候选**的自由文本中
   删除为无数字的“差额/差异”表达：
   - 字段除该字面量外能通过全部既有形状、权限、来源、算式、货币符号和受控结论门；
   - 该字面量是同币种、非零金额，紧邻“差额”或“差异”，不是付款、利率、期限、比例、请求或结论；
   - 该字段当前授权来源内存在两个不同的、服务器投影的同币种金额，确定性绝对差恰好等于该字面量；
   - 解释器只删除模型写入的差额数值，绝不把该值、计算式、正式金额结果或新的法律判断写回候选文本。
3. 每次降级必须产生版本化 `model_output_normalization` 回执：路径、未绑定字面量哈希、精确来源编号和
   固定原因码都进入候选包。候选仍只能是 `NEEDS_LAWYER_REVIEW`，不得自动批准、激活办案计划、生成
   可提交文书或发出任何外部动作。
4. 其他任何未绑定数字、无法唯一由已授权来源复算的差额、算式、百分号、货币符号、正式金额、
   结论、批准或提交措辞继续失败关闭。降级回执本身不构成事实、交易、规则、计算结果或律师立场。
5. 候选包升级为 `case-agent-lawyer-decision-package-v3`；独立解析器必须验证回执形状、原因码、
   来源范围和“有回执才可标记为已降级”的对应关系。v1/v2 仅按其各自既有规则只读解析。
6. 对 V4 只允许用这条新解释器进行零模型调用、零持久化写入的封存响应回放。回放若成功，结论只能是
   “历史封存响应可形成带降级回执的律师审阅候选”；它不是新的 V4 运行，也不允许 V5 或重试。

## 后果

- 律师可看到仍有用的“差额需核验”分析，而不会看到模型伪造或自行计算的差额金额。
- 审计能区分原始模型行为、代码的受限降级以及律师后续决定；任何异常频繁的降级都会成为模型质量
  指标，而不是被静默掩盖。
- 这只处理一个受限的 A1 审阅候选恢复路径。真实律师认可、浏览器旅程、文书批准、备份恢复和商用
  放行仍按原计划分别验收。
