# ADR-0069：来源绑定数字策略修复后的单次最终 Agent 验收

- 状态：已接受
- 日期：2026-09-04

## 背景

ADR-0067 定义的 v3 合成案件已完成一次真实、单次的律师决策包模型调用，但旧解释器把任何数字字面量一律视为模型越权，因而在写入候选包前将运行停在 `WAITING_INPUT`。该运行、外发请求和归档响应必须保持不可变，不能续发、改写或伪造为成功。

ADR-0068 已将策略改为：模型只能逐字引用服务器投影且由对应来源编号授权的事实日期、金额或原币种；任何自行计算、货币符号、百分比、正式金额结果、批准、锁定或外发仍然被硬性拒绝。封存 v3 响应已在零新模型请求、零持久化写入的只读回放中通过该解释器，并形成 `case-agent-lawyer-decision-package-v2` 律师复核候选。

只读回放证明了已采集真实响应在当前策略下可用，但不证明当前运行时能从一次新调用连续走到动态办案计划、律师审查门和 DOCX/PDF 审阅候选。为避免无限重试，允许一个新的、隔离的最终合成验收场景。

## 决策

1. 新场景固定命名为 `managed-defence-source-bound-numeric-v4`，使用独立、确定性的案件、运行、幂等键和外发请求身份；只允许 88 页合成资料，绝不指向客户案件。
2. v4 默认在任何恢复标志下均失败关闭。唯一例外是本 ADR 记录的 `--recover-v4-pre-model-source`：它只允许在精确的、零法律事件、零 Agent 运行、零外发记录、案件版本仍为 30 的 V4 检查点执行。该例外不是模型重试，不创建新案件或新 V4 身份，也不允许 v5。
3. 启动前必须同时满足：受管 API 和 Worker 健康；Docker 引擎响应；宿主 Data 分区可用空间满足 [ADR-0070](ADR-0070-v4-runtime-resource-floor-revalidation.md) 的 V4 专项下限；当前镜像确实打包 `case-agent-lawyer-decision-package-v2`；Qwen DNS/TLS 仅握手预检成功；相关回归和 v3 只读回放已通过。
4. v4 首轮最多一次真实 Qwen 律师决策包请求。成功条件不是模型文本本身，而是：精确一笔已知外发、来源绑定候选包、独立验证、律师审查动态计划、第二轮零外部调用的确定性答辩状 DOCX/PDF 审阅候选。
5. 任一阶段失败即记录准确状态、停止自动动作并输出证据；不得重发模型、篡改 v3/v4、自动批准事实或法律立场、锁定提交件或对外发送材料。
6. v3 继续保留为历史 `WAITING_INPUT` 运行；v4 成功也不会追溯修改 v3 的失败结果。

## V4 预模型法源恢复条件

这项恢复只因 V4 在模型调用之前被官方公开站点的临时可用性阻断而允许，且必须同时满足：

1. 通过只读数据库审计确认 V4 仍处于完整受控输入版本 30，法律事件、法源包、Agent 目标、Agent 运行和工作计划均为零；由 Agent 运行数为零及其外发表外键约束证明不存在外发。
2. 只读查询同一律所内已审批法源包，要求来源 ID、内容哈希、发布者、效力层级、URL、精确定位、媒体类型、验证状态和许可状态与冻结合同逐项一致。
3. 从该已审批合成案的 matter-bound 私有对象读取字节，重新认证媒体类型、长度、SHA-256 和条文标记后，按正常 no-overwrite 规则复制到 V4 的独立 matter-bound 私有链。
4. 该恢复不得访问公网、枚举对象存储、读取或发送客户材料、调用模型、创建 Agent 运行或改写历史审计。任何来源、对象、版本或状态不一致均停止。
5. 复制后仅恢复 V4 原有受控输入与法源登记步骤；随后仍只允许该固定 V4 的一笔首次模型调用。若它失败，不创建 V5，也不自动重试。

## 后果

- 这是最后一次有成本的合成模型验收，不是常规重试循环。
- 若通过，可证明当前 Agent 在真实受管模型、受控来源、律师审批和确定性文书交付之间的完整链路；仍不等同于执业律师对真实匿名案件的业务验收，也不等同于法院提交资格。
- 浏览器用户旅程仍须在用户指定浏览器中另行验收；该限制不应被命令行或自动化浏览器绕过。
