# ADR-0114：已取消或过期的读卷不能阻塞当前材料核对

状态：`Accepted`

日期：`2026-09-10`

## 问题

统一办案 Agent 的材料覆盖投影此前只要看见“读卷任务成功且图已核验”，就把原始页面视为
已处理。若该运行之后被取消或标记过期，材料整理候选会在律师界面变为历史记录、不能确认，
但新一轮统一办案又误以为无需读卷。这会把律师卡在“材料已处理”的假状态。

## 决定

当前材料覆盖只接受同时满足以下条件的读卷任务：运行处于 `READY_FOR_REVIEW` 或
`COMPLETED`，未过期，未取消，且任务尝试成功、任务图已独立核验通过。被取消或过期的
运行及其候选仍作为审计历史留存，但不计入当前覆盖。

## 后果

下一轮统一办案会重新建立可供律师核对的材料整理结果，而不会把已不可操作的历史候选当作
当前案情。该改变不自动确认任何事实、收付款或法律立场；重新读取仍受既有预算、来源范围、
审批和审计规则约束。
