# ADR-0061：官方法源对象缺失校验头时的全字节只读恢复

- 状态：已采纳
- 日期：2026-09-04
- 关联：ADR-0054、ADR-0055、ADR-0057、ADR-0058、ADR-0060

## 背景

受管被告应诉验收把最高人民检察院公开法律文本以固定的租户、案件、内容哈希和
`If-None-Match` 私有对象键保存，再将仅内容寻址的定位符登记入法律账本。一次本地
MinIO 兼容性运行证明：对象已加密写入，长度、媒体类型、租户/案件/内容元数据和
逐字节 SHA-256 都正确；但该网关在 `HEAD` 响应中省略了请求时提供的
`ChecksumSHA256` 字段。旧实现将“校验头缺失”直接等同于“对象写入失败”，既没有
法律账本记录，也没有 Agent 运行，却留下了可验证的不可变对象。

不能为绕过该问题而忽略校验、覆盖对象、删除对象、重新上传，或直接执行模型。

## 决策

1. `ChecksumSHA256` 字段存在时必须与预期 SHA-256 严格一致；字段存在但错误、长度、
   媒体类型、服务端加密或全部租户/案件/内容元数据不一致，均继续失败关闭。
2. 仅当该字段**完全缺失**时，才允许兼容路径。该路径对固定的对象版本进行一次受限
   完整读取，逐字节复算 SHA-256、校验长度和媒体类型/内容形状，再读取第二次对象头。
   两次对象头的完整指纹必须相同；任何变化、超限、读取失败或哈希不一致都拒绝。
3. 新写入后的兼容验证和不确定写入后的恢复共用上述只读证明。恢复只针对由
   `firm_id + matter_id + content_sha256` 推导出的唯一对象键，绝不扫描桶、枚举对象或
   向其他案件泄露对象存在性。
4. 受控验收的法源写入若返回“状态未知”，只允许执行一次上述只读恢复；恢复通过才
   继续法律账本登记。恢复失败必须以明确的“未继续模型运行”状态停止，不能再上传、
   不能创建第二个案件、不能调用模型。
5. 固定合成验收优先恢复已审核的精确来源哈希、字节数和材料标记；只有该对象确实
   不存在时才请求公共网站。对象的服务端不可变创建时间作为“进入私有来源链”的
   捕获时间，不能伪装成一次新的网页抓取。来源对象存在但任何完整性校验失败时，
   不得退回网页下载以绕过异常。

## 后果

- 兼容 MinIO 等省略 `HEAD` 校验头的 S3 网关，但完整内容哈希和稳定的前后对象头仍是
  不可省略的完整性证据。
- 一个已存在的正确对象可被安全复用到此前中断的固定合成验收；该恢复不修改原件，
  不产生模型调用，也不受公共网页短时限流或可用性影响。
- 官方法源对象的登记、读取和动态法源文本抽取都继续受同一私有、案件绑定、只读
  完整性边界约束。
