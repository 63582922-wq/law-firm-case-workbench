# ADR-0111: 首次律师研判不把未确认提取候选直接作为模型前提

日期：2026-09-10  
状态：已采纳

## 决定

被告应诉的首次律师决策包只接收已治理的代理边界、已确认或明确争议的事实及诉请、已核验法源/规则和律师待核事项。`transaction-candidate`、`fact-candidate` 与原始材料继续保留在材料核对链路，不能被一次性拼入首次模型请求。

## 原因

候选记录只是从原件提取的待核内容，不能因为进入分析上下文而被误认为案件事实。将大量候选一次性放进严格 JSON Schema 请求还会使模型在没有实质增益的情况下承受过大的上下文和输出约束，降低首轮研判的可用性与可恢复性。

## 后果

律师仍可在材料页核对每一条候选并回到原页；未决事项作为明确的核对任务进入决策包。候选经律师确认后，才以受版本约束的案件事实或交易进入后续分析和文书链路。原件、候选及其来源绑定不删除、不降级。
