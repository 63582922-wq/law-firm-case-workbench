# ADR-0095：明确的局部材料读取范围

状态：内核分阶段实现，未开放创建入口或恢复旧运行。

真实留存提案诊断发现：只要求识别一页图片的目标仍自动吸收整案法源研究义务。
自然语言目标不能成为权限或免除义务的依据。新增目标 v3 的 material_read_refs，
绑定非空、去重、排序的具体证据页或材料对象编号，进入目标摘要。
默认空范围保持旧 v1/v2 字节及语义：整案研究义务不能因此被删除。

明确局部范围只允许 pdf_reading、office_reading、image_visual_ocr，且所有任务输入
必须位于该范围并完整覆盖它。不能附带文书交付、激活计划、恢复重提取义务，不能读其他
事实/交易或研究来源。来源版本、可读性、技能授权、外发批准及费用门保持原有校验。
局部执行不解决或关闭整案法律缺口，也不代表整案任务完成。

实施计划：目标摘要/持久序列化兼容及编译门 → 聚焦正反测试 → 经授权的服务/API入口
及精确快照投影 → 原提案的追加式范围复核和容量复核 → 实际 OCR 与用户流程。
旧目标和提案摘要不可原地重写；在追加式恢复合同完成前，禁止把此新字段套到历史运行，
也禁止创建新的付费规划请求掩盖旧失败。不得仅用空 requested_deliverables 或关键词判断局部范围。

本地复核候选必须分开保留 original_goal_hash、original_proposal_hash、planning_hash 与
新的 effective_goal/derived_proposal/derived_proposal_hash。任务内容和输入快照不改变，
派生提案只能修改其目标关联，明确不是新的模型响应。编译器只允许按实际所需增加输出容量，
候选硬上限64MiB，时间/外发次数/费用等其他预算不可变化。候选不构成批准或执行权限。
数据库成功交换核验、当前案件权限和版本、原失败运行状态及追加式批准仍为独立必需条件。

事件绑定原目标、原提案、供应商请求、快照、明确来源、原/新输出预算、有效目标、派生提案、
编译图及复核人摘要。重放构建有效目标和输出预算，原RUN_CREATED和供应商原响应不变。
当前只实现事件类型/严格序列化/状态机；不加入任何普通写授权，数据库事件许可仍拒绝。
