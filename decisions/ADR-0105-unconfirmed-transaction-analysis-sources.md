# ADR-0105：未确认交易也可以被分析，但不能成为正式金额

状态：Accepted（实施中，非整案验收）

原始材料抽取已完成，若分析只能读取正式交易表，就迫使律师先做完判断。新增独立
TRANSACTION_CANDIDATE / transaction-candidate来源，不复用已确认交易类型。
只从同案、独立验证成功且已持久暂存的抽取记录读取；逐条重验候选哈希和原页绑定。
正式推广后的记录由正式台账提供，不在候选来源重复引用。现有律师决定、原因和材料名
进入绑定摘要及正文，原文仍是数据，不是模型指令。

当前权威读取返回48条未确认交易候选：新流水43条、法院材料原有5条。不能把后者当成
实际履行记录；分析须区分诉状陈述和流水，以及重复/冲正/第三人/手续费/币种。
所有新来源状态固定REVIEW_REQUIRED，仅开放context和分析能力；文书入口拒绝把它们
作为确认前提。工作计划引用复用WORK_PLAN，不借此获得金额计算或正式事实审批权限。

0095补充计划来源约束；网页来源链接回到原页。读取合同与接线不授权新的外发调用，
原任务下一分析阶段仍需累计预算、旧成果保留及范围绑定的续阶段入口。

## 未确认事实来源补充

同样允许 FACT_CANDIDATE / fact-candidate 表达主体、户名等材料记载。它不等于
CASE_FACT，固定REVIEW_REQUIRED；只进入context/analysis及WORK_PLAN引用。
0096单独约束类型、引用前缀和状态，不修改已应用0095。两类来源均排除已推广记录，
并排除case_facts.correction_candidate_id已绑定的旧候选，以免覆盖已经提交的纠正。
未提交私人草稿不读取，也不当作授权分析数据。当前真实只读装配为48交易+8事实候选，
共67项来源，均被分析任务选取；这个结果不是模型执行或法律实体结论。
