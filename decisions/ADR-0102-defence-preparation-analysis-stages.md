# ADR-0102：准备、初步研判与正式文书分阶段

状态：Accepted（实施中，非整案验收）
日期：2026-09-10

现有目标以DEFENCE_STATEMENT为最终产出，却将事实、诉请、批准法源全部齐备作为任何
研判的入口，导致已读材料仍反复回到准备。原始准备还逐页创建任务，8页就占用8个
300秒读取预算，无法进入默认1200秒执行预算。两者是流程设计断点，不是模型能力结论。

1. 目标与目标摘要不改写。准备阶段按已安装读取器批量读取同类授权输入，保留每页引用。
   对可供既有事实抽取器消费的原生PDF页，安排一个依赖读取完成的候选抽取任务。
   使用现有供应商、原审批及编译器预算；不新增通用规划模型、不自动扩容预算。
   OCR/Office不会被伪装成原生PDF抽取输入；读取或抽取候选不是应诉资料完成。
   混合材料中的OCR通过已安装抽取投影器的直接依赖读取，保留OCR来源类型及强制复核
   标记；没有可授权的原生页入口时不凭空创建抽取任务。Office转换到页级的衔接尚待补齐。
2. 初步研判要求确认代理情境和至少一项确认的来源事实，不要求律师先批准法律规则。
   只纳入已治理的结构化来源；未确认/冲突记录不得静默视为确认。初步研判保留来源绑定的
   候选/争议/否认事实及诉请原状态、摘要和引用，交由已有context与analysis合同明确标记
   不确定性；不得过滤掉不利材料，也不得提升为确认。至少一项确认事实仍为进入条件。
   正式文书继续要求确认来源，不因初步研判接受未决来源而放宽。缺诉请、法源、规则
   由既有研判合同报告缺口，不能虚构法律依据。原件不直接交给新的研判供应商。
3. 已激活文书计划沿用完整、严格的来源前提，保持零模型外发；不因分析放宽而放宽出稿。
4. 各阶段沿用累计预算和快照失效机制，不能通过新建目标或重规划清零已用费用/调用次数。
   当前单次调用上限不自动变为多次授权；准备后剩余额度不足必须保留成果与继续检查点。

Worker普通编译与封存提案恢复编译现均扣除已有尝试/调用/时间/费用/输出用量；阶段
切换不清零总预算。容量不足保留既有成果和提案，使用NEXT_STAGE_BUDGET_REVIEW_REQUIRED
检查点，不分派后续任务。调整费用/调用额度的明确命令入口仍待完成，不能称已能自动续跑。

事实抽取此前错误地以0费用编译及登记。新任务上限120分，发出请求前按UTF-8字节数
加4096个上下文余量、32768输出上限、无缓存/高峰价格作保守预留，超限不外发。
价格基线为2026-09-10核对的DeepSeek V4 Pro输入9元、输出27元/百万token，来自
[官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。此为预算占用，
不是供应商实际账单；不利用缓存或低峰折扣放大可用预算。历史0费用任务只能沿用旧键
查询恢复，不允许新发送；不重写历史费用。后续实际运行前仍须核对价格有效性。

本轮实施准备批处理、初步研判入口及剩余预算编译。完整的同目标推进、预算调整、浏览器必要
决定、独立证据目录与无预置事实整案验收仍须闭合；不把局部路由测试称作完成。

未决事项来源衔接采用独立bound-review-obligation-v1合同，不将律师暂缓原因写成CASE_FACT。
合同保留当前决定摘要、版本、状态、原因全文及原页引用，正文亦计入内容哈希；仅接受
已在同案权威事务中核验的暂缓、补证和拒绝重复信号。重抽取义务不能用“读到说明”替代。
该合同不授权新外发、不解除暂缓、不改变正式文书来源白名单。当前仅合同及4项检查已实现；
权威投影、context读取、分析来源类型和结果来源回查必须整体接通后才可发起使用该类型的运行。

源码接线补充：REVIEW_OBLIGATION/review-obligation为独立分析来源，复用LEGAL_GAP能力类别，
由权威事务当前信号构造。窄投影仅重绑定已经核验的同ID事项，原页引用保留在完整投影与
事项内容哈希中；context再次在同事务核验，analysis将其与既有风险锚点并列而不替代事实。
不授予文书/法源能力。现有计划来源数据库白名单尚未扩展，计划提升对该未接通类型明确拒绝；
需独立前向迁移与浏览器来源定位后才能称完整接线，不能以运行时自动放宽替代。

材料覆盖补充：权威事务按页读取成功抽取及同图独立PASSED证据，将extraction_complete
作为原页处理元数据纳入规划摘要，不改变原件哈希、证据审批状态或事实状态。
窄分析投影保留未抽取页、排除已处理页；规划收到待处理原页时优先准备/抽取，即使已有事实。
未知旧元数据不被伪造为完成；真实安装抽取台账的仓库必须计算布尔覆盖，不靠候选数量估算。
该改变不增加预算、不借只读研判队列范围外发原件；补充抽取仍需现有来源授权和执行边界。

续阶段设计：沿用原Run，以来源覆盖摘要、旧图摘要、事件版本和审批人绑定补充读卷。
仅选未抽取原页，单阶段最多1次调用/120分，不恢复失败或外部结果未知的任务。
总额度为max(旧额度, 已消耗+本阶段额度)，已用量不清零，旧成果不作为律师认可。
新增case_agent_material_stage仅实现服务端续阶段提案及6项边界检查；它不写事件、不授权
外发。持久化命令必须在同事务重读案件、覆盖和事件版本，核验审批角色后追加记录，
再把来源范围交给受控编译和队列。不能通过现有只读研判例外直接发出抽取请求。
