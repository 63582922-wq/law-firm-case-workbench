# ADR-0128：可先执行具备来源的内部审阅成果

状态：`Accepted`

日期：`2026-09-11`

## 问题

同一案件计划可同时包含已具备确认来源的审阅成果，以及诚实标注为“待补信息”的可选成果。例如，已有
事实、诉请、法源和证据页时可以形成案件审阅意见、答辩状候选和证据目录，但没有已确认的收付款记录时
不能形成收付款核对表。此前系统将后者作为整份计划的全局阻断，律师无法取得已准备好的内部工作成果。

## 决定

- 保留源 Agent 运行提出的完整成果意图、计划事项和待补信息，不把缺失项目伪造为已完成，也不删除其审计记录。
- 激活时仅选择 `ACTIONABLE` 的内部审阅文书项作为第二次执行范围；至少必须有一项可执行成果。
- 任何标记为必须交付的成果仍须具备确认来源。缺少来源的可选项保留在计划中，供律师补充材料后重新研判。
- 数据库触发器要求第二次执行的成果集合是源目标的受控子集，并逐项核验其当前为内部、可执行文书。它不能新增成果种类、扩大来源或绕过律师终审、提交锁定和外发边界。

## 后果

律师界面可以清楚地显示“现在可审阅的成果”和“仍待补充的材料”，而不是把内部限制误呈现为整案不可用。
收付款核对表仍必须等交易记录确认后才会进入后续计划；系统不会计算、批准或提交任何法院材料。
