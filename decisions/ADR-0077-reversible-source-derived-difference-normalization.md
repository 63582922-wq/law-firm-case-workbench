# ADR-0077：受控差额脱敏同时识别“差额在金额前”的中文语序

状态：`Accepted`

日期：`2026-09-05`

## 背景

M2 的唯一一次 `qwen3.7-plus` 调用已正常结束，原始响应、用量回执和私有归档均已认证。硬控制器在
`issues[1]` 的补证文字中发现模型写入一个不直接存在于来源中的金额，因而正确阻断了运行，未形成
候选文书。

只读诊断进一步证明：该金额不是任一来源的原样事实，却恰好等于同一字段已引用的、同币种的两个
受控数值事实之差，并且这对数值事实在当前字段范围内唯一。既有受控脱敏已支持“金额在前、差额/差异
在后”的中文表达，例如“5,000 元差额”；但 M2 使用的是等价的“差额 5,000 元”语序，未触发该
窄门。该情况不是接受模型计算结果的理由，更不是重新调用 M2 的理由；它是一个已定义、证据可证的
展示降级规则遗漏了常见语序。

## 决策

1. 保持原始供应商响应不可变，M2 的已记录外发、失败回执和 `WAITING_INPUT` 状态不改写，也不重发。
2. 在既有“来源派生差额脱敏”中，仅增加一种等价的直接标签语序：金额前紧邻“差额”或“差异”（可有
   空白）。不接受“为”“约”“超过”等扩展语义，也不接受其他数字、货币、百分比、期限或计算表达。
3. 两种语序都必须同时通过已有全部事实门：待移除的量为正金额、该字段自身未能直接绑定该金额、同一
   字段引用的来源中恰有一对不同的同币种金额事实，其绝对差精确等于该量，并且数值事实对唯一。两个
   数值事实可以共存于一个不可变来源对象；该对象必须同时被数值索引命中并进入归一化回执。否则仍由
   严格解析器拒绝。
4. 归一化只能从候选自由文本中删除该数值字面量；不补写金额、不推导法律结论、不改变模型原始归档。
   候选仍记录字面量哈希、原因和精确来源引用，且仍是“待律师复核”而非可提交成果。
5. 修复先以单元回归和 M2 已封存响应的零外发、零写入回放验证。通过这些门后，M2 可继续后续的候选
   编译与文书渲染门；不得借此创建新的模型调用。

## 后果

- 安全边界没有放宽为“模型可以计算差额”：只有服务器可独立证明的唯一差额数字才会被删除，不会进入
  律师候选、正式金额、计算工具或法院材料。
- M2 提供了真实模型对完整受控案卷进行分析的证据；但只有完整只读回放和文书验收通过，才可将该次
  已封存调用的结果视为可供律师审阅的候选交付链。
- 任何无法满足唯一来源对、字段引用或直接标签条件的输出继续失败封存；该 ADR 不是无休止重试机制。
