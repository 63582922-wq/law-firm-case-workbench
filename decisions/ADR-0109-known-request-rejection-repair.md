# ADR-0109：已知HTTP请求拒绝的受控修复

状态：Accepted（实施中）

新增显式修复事件用于已知HTTP400、无成果且记录成本为零的分析失败。不是结果未知
重试，也不是质量修订循环。必须绑定失败attempt、原请求摘要、不同的新请求摘要和原因。
数据库核验已有失败事件及外发记录；发送前重验修复后的请求摘要。保留全部既有用量和
失败记录，只允许一次新增受限分析，修复阶段不能自我续期，不重抽材料、不改变事实审批。

固定合成验收已有4次外发/119分占用，下一累计上限5次/239分，新请求预估上限114分。
该估计不是账单。用户已授权必要调用；修复后的真实响应仍须内容及用户旅程验证。
