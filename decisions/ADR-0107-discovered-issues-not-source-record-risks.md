# ADR-0107：争点应由跨材料分析提出，不等同于来源记录

状态：Accepted（实施中；尚未切换线上分析合同）

真实第三图分析遗漏重复、退款、币种、费用，同时将案号及日期写为风险。现有合同从
固定CASE_FACT选锚点并强制相同数量的风险与攻防，造成产品目标和模型输出结构冲突。
单纯加提示、加输入或换模型不足以修正这种结构。

新争点发现合同允许模型提出一至二十项待复核问题，关联多条原件候选，并分开我方和
对方立场。服务器根据来源版本、问题及引用生成proposed-issue标识；不写正式争点表。
全部来源必须被逐项归为争点相关、背景或关联性待核，但背景不强制成为风险；来源
处置和争点引用双向一致。遗漏材料、外部引用、假审批字段均被本地拒绝。

这只是来源完整性和结构验证，不证明模型的归类或法律判断正确。下一步须把同一次
分析请求和成果编译切换到此动态合同，继承金额与法律边界、来源回查和旧版本可读性。
禁止将本模块测试通过表述为新模型分析成功；当前运行仍使用旧合同，未新增外发。

实施补充：新版候选完整保存输入版本及来源投影，读取时重新验证摘要、处置、问题ID
和供应商用量。既有公开候选入口按schema分流，旧版本继续可读；网页单独呈现自主
问题及行动。适配器源码对未确认抽取来源选择新版；现有已确认台账路径暂保留原合同。
真实新版运行尚未开始，文书消费与修订续阶段仍待闭合；不能提升为已完成或律师接受。
