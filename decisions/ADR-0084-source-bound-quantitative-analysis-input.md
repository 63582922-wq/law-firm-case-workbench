# ADR-0084：研判可读取有来源的量化事实，正式计算仍由程序负责

状态：Accepted

日期：2026-09-05

## 需求与判断

依据用户授权的项目审计整改，律师 Agent 必须理解材料中的时间和金额关系。
ADR-0080 把“禁止模型形成正式计算结果”扩大成“模型不能读取日期金额”，削弱了研判输入。
读取来源事实不是确认事实，也不是批准法律立场。本决策替代 ADR-0080 第 1 条的全面隐藏策略；
不改变其输出数量门、历史失败记录和禁止自动重跑的边界。

## 实施计划及契约

1. 在既有受控来源目录的每条来源内增加 `quantitative_facts`，只收录该条标题、正文中已经被
   本地识别的显式币种金额与有效完整日期；不从其他来源拼接，不计算差额，不猜币种或日期。
2. 每项包含与正文对应的稳定标签和规范化值，金额以十进制字符串传递，日期以 ISO 日期字符串传递。
   上层来源编号、类型和状态继续约束解释：争议事实和对方主张不能升级为已确认事实。
3. 普通数字不展开，以避免将账号、编号或无单位数值误当成金额。现有解析器未识别的中文金额、
   简写日期和比例仍属输入能力缺口；不得宣称已解决全部材料理解问题。
4. 请求显式标识 `SOURCE_BOUND_QUANTITIES_V1`。模型可研判时间和金额关系，但输出继续使用来源引用和
   定性表述；不得形成差额数值、利息、期间计算或将差异解释为已发生的付款。正式计算必须走确定性工具。
5. 只改变未来请求构建，不发送请求、不增加供应商、不改变外发审批和费用上限，不改写 M1/M2/M3。
   新请求内容进入既有请求字节及哈希归档；历史封存响应不重新外发。

## 复核与停止条件

用合成来源验证日期、不同币种金额和标签逐条对应；来源状态保留、编号不展开、未计算差额。
运行既有输出拒收和来源绑定回归测试。无需付费调用验证请求投影。
代码通过不证明模型分析质量；正常端到端验收仍需原始材料独立样本、完整文书和律师质量评价。
