# ADR-0080：模型仅接收定性量化标签，并拒绝中文量化自由文本

状态：`Accepted`

日期：`2026-09-05`

## 背景

M3 的唯一一次 `qwen3.7-plus` 受控调用已正常返回并被私有归档。严格解释器在
`adversarial_analysis[1].residual_risk` 中发现模型把两个来源金额相减后写成新的金额，并将其进一步
描述为可能的现金交付或借款事实。该数值不是任一来源的原样事实；它也不是 ADR-0077 所允许的、紧邻
“差额/差异”标签的展示型字面量。因此 M3 必须保留为失败，不能通过扩展差额脱敏将它改写为候选。

这暴露的不是网络或模型连接问题，而是模型仍能读取原始量化事实，并可能在自由文本中把它们重新组合。
同时，原解释器只精确解析阿拉伯/全角数字；中文书写的金额、日期或比例若未被单独识别，可能逃过同一
量化事实门。

## 决策

1. 对未来模型请求，服务器仍保留原始案件投影、来源哈希、数值索引、确定性计算和律师候选来源目录；
但发送给模型的 `source_catalog` 与对方路径摘要中的日期、金额及其他可识别数值一律替换为稳定、无数值
的定性标签，例如“金额事实甲”“日期事实乙”。同一原始数值在一次请求中使用同一标签。模型不再看到
原始数值，律师和确定性组件仍可从来源编号查看原值。
2. 所有模型自由文本改为“定性表达”合同：不得出现阿拉伯、全角或中文数词、日期、金额、比例、期限、
货币符号或运算；需要量化时只填写受 Schema 限制的来源编号数组。候选件由服务器独立展示原始来源事实，
不要求模型复述。
3. 本地解释器新增中文量化门：出现中文数词加金额/日期/比例/期限单位，或在金额、本金、利息、差额、
诉请、付款、还款、借款、余额、价款、数额等敏感语境中的中文数量，一律拒收。该门不会把中文量化文本
解释、归一化或补写为事实。
4. 不扩展 ADR-0077 的可逆差额脱敏范围。M3 中“可能为现金交付或其他形式借款”的文字是实质性事实
推断，不是安全的展示降级对象。M1、M2、M3 的状态、外发记录和原始归档全部保持不变；不得创建 M4 或
自动重试。

## 后果

- 新模型请求的数据最小化更强：模型获得的是关系和来源定位，而非可供自行运算的原始量化值。
- 即使模型尝试用中文书写数值，也会在本地失败关闭；不会进入律师候选、计算、文书或提交链。
- 历史阿拉伯数值的来源绑定解析保持兼容，以便只读审计旧封存响应；未来请求通过输入最小化和提示合同
避免依赖该兼容路径。
- 此项修复只提升下一次经过独立授权的真实验收机会；它不把 M3 的失败改记为成功，也不构成商用放行。
