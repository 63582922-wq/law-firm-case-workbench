# ADR-0110：客户工作台只呈现办案动作，不呈现研发控制面

状态：`Accepted`

日期：`2026-09-10`

## 决策

律师客户端的默认首页只回答四件事：当前案件处于什么位置、下一步要做什么、哪些事项需要律师决定、哪些成果可以审阅或下载。

模型、任务图、Worker、调用参数、运行计数、服务装配和开发说明不属于律师完成办案任务所需的信息，默认不在案件首页、材料页或成果页展示。它们仅可在受限的运维/审计界面读取。

## 后果

- 首页使用“确认案件 → 整理材料 → 审阅问题 → 形成文件”的案卷路径，不要求律师理解 Agent 的实现方式；
- 未满足前置条件时，界面说明用户下一步动作和保留状态，不用“服务未装配”“总控不可用”等研发术语；
- 仍保留来源、审批、失效和外发边界，但只在用户作出相关决定或审阅相关成果时展示；
- 该收敛不改变后端状态机、审计记录、原件保全或律师审批门，也不把任何候选伪装为正式结论。

## 验收

1. 律师打开案件首页后，十秒内能找到唯一的下一步；
2. 默认首屏不出现模型、Worker、调用、任务图或开发模式说明；
3. 材料、分析和文件的状态都以用户动作和可审阅成果表达；
4. 浏览器实测仍能完成建案、材料接收、查看成果和下载路径。
