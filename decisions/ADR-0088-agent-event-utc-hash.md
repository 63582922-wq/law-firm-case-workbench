# ADR-0088：Agent 事件时间摘要统一 UTC

状态：接受；2026-09-05。

原生 PG16 实测：UTC 写入的 RUN_CREATED 以 Asia/Shanghai 会话时区读回，直接 isoformat
产生不同字符串，既有摘要校验拒绝事件，导致 Worker 无法认领规划。timestamptz 存储的是时间点，
不保留提交方的时区表示；不能将数据库返回的时区字符串作为事件身份。

事件摘要的 occurred_at 改为 UTC isoformat，继续保留微秒。现有 UTC 写入的摘要不变；
不关闭摘要校验、不重写历史、不将损坏记录当作成功。若历史确有非 UTC 字符串签出的摘要，
须单独核对原始证据与版本迁移，不能批量重签或静默忽略。

回归检查 +08/-05 表示得到同一摘要，实际时间变化一微秒仍拒绝。原失败库原事件未改写，
修复后真实 Worker 成功回放、认领并读回新增 PLANNING_STARTED。无外部模型调用。
