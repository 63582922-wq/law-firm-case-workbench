# ADR-0076：M2 可在严格预模型边界复用新鲜的同律所官方法源快照

状态：`Accepted`

日期：`2026-09-05`

## 背景

M2 `m2-source-qualified-post-reconciliation-acceptance` 的首次启动已经创建固定合成案件，并完整写入
材料、代理姿态、事实、诉请及被告回应，到达版本 30。随后天津通信管理局的固定 URL 当前无法按
ADR-0075 的“重新下载且精确匹配”合同取得原文，系统在模型调用前停止。

该停点没有法律事件、法源包、Agent 目标、Agent 运行或外发记录。它不是模型失败，也没有消耗 M2
的唯一模型调用额度。与此同时，M1 已在同一律所内保留一份已验证、`ACTIVE`、已进入 `APPROVED`
法源包的同 URL、同 SHA-256、同媒体类型的公共法源对象；该对象的原始获取时间可审计。

把合成验收的成功与否完全绑定到一个已验证公共网页在下一分钟是否可达，会把网站可用性误报成
Agent 能力问题；但把缓存内容伪装成新网页抓取，或跨律所/跨来源宽泛复用，也会破坏法源可追溯性。

## 决策

1. 仅允许 M2 使用显式的 `--recover-m2-pre-model-source` 恢复路径。它必须先逐项证明固定 M2
   案件仍停在完整受控输入后的版本 30，且法律事件、法源包、工作计划、Agent 目标、Agent 运行和
   外发均为零；不满足即停止，不新建案件。
2. 该恢复只能读取同一律所、已 `VERIFIED`、`ACTIVE` 且已进入 `APPROVED` 法源包的精确公共来源。
   `source_id`、发布者、权威级别、URL、条款定位、媒体类型、SHA-256 和可见正文标记必须与 M2
   冻结合同完全一致。查询为事务内只读查询，不能枚举对象存储或扩展主机允许列表。
3. 恢复读取 M1 的确切、内容寻址私有对象，并再次校验媒体类型、字节数、SHA-256 和可见正文；随后
   仅以不可覆盖方式复制到 M2 自己的私有对象范围。M2 登记的获取时间仍是原始捕获时间，绝不伪装成
   当前网页抓取。
4. M2 只接受原始捕获时间不超过 24 小时且不晚于受控时钟超过 5 分钟的快照。超时、未来时间、任一
   元数据差异或对象读取失败都会在模型调用前停止。
5. 该恢复不访问公共网页、不发送客户材料、不调用模型，也不自动重试。只有来源复制、法源登记和
   固定输入合同全部通过后，M2 才可继续其原定的一次 `qwen3.7-plus` 调用；该一次调用仍受
   ADR-0075 和 ADR-0074 的成本、时间、审计与不重发边界约束。

## 后果

- 真实验收继续证明 Agent 对受控材料和可追溯法源的工作能力，而不是误把短暂网页不可达当成模型
  能力结论。
- M2 的法源仍可回链到官方 URL、原始捕获时刻、版本化法律记录和两个独立的同哈希私有对象；不会
  将 M1 的案件材料、模型结果或审批状态带入 M2。
- 这不是生产案件的自动法律更新机制。生产环境仍必须由律师或受控法源捕获流程决定何时重新验证
  效力、何时替换来源以及哪些已批准输出需要失效。
