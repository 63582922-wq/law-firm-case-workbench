# ADR-0090：可选重试不挤占完整计划的首次执行

状态：接受实现，部署及已有提案恢复待验证。2026-09-06。

真实合成材料规划已成功留存三任务提案，但编译器把本地任务三次尝试全部预留，
使可在600秒内完成一次的540秒计划被1380秒的重试最坏预留拒绝。
运行预算和原提案都是不可变审计对象，不能为通过验收改写；也不应重新付费生成同一提案。

真实留存提案复核更正：上述540/1380仅计模型三任务，漏计服务器自动补入的法源研究计划。
实际四任务首次预留660秒，原600秒仍必须拒绝。可选重试分配修复不能据此声称已恢复本次运行。
聚合超额异常另携维度、所需额度、可用额度和最终任务数，供后续受控恢复诊断；不自动提高额度。

编译器将服务策略的 max_attempts 视为上限。原计划全部预留能满足预算时保持原图不变。
超限时先为每个任务保留一次执行，按原有聚合规则核验所有预算；首次完整计划仍超限则拒绝。
随后按任务序号逐轮分配剩余重试，只对 IDEMPOTENT 任务分配，且不超过原策略上限、
运行尝试总数和累计运行时间。非幂等任务保留原尝试上限，不借此改变未知外发恢复协议。
不删除/改写任务或依赖，不缩短单次超时，不改变外发、费用、输出、审批、权限或模型提案。
最终预算进入新编译任务图摘要，已有已接受任务图不重编、不回写。通用及动态计划编译使用同一规则。

该修复是可执行预算分配，不声称任意规划一定可行。历史成功提案的重编还须走既有
恢复和当前来源核验；不允许直接SQL覆盖运行预算、事件或失败记录。
