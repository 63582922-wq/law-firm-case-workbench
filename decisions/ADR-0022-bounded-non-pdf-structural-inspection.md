# ADR-0022：非 PDF 案卷材料先做有界结构检查，再进入隔离转换

状态：已接受并实现结构检查与可见异常队列；规范化产物登记尚未实现

## 背景

恶意文件扫描为“干净”不代表文件可安全解析。Office 容器仍可能包含宏、ActiveX、嵌入对象和外链；ZIP 可能包含路径穿越、符号链接、加密项或压缩炸弹；伪造扩展名、超大图片、二进制伪文本和危险邮件附件名也不能直接交给转换器。

同时，律师必须看见每个文件的处理结论，不能只看到汇总数字，也不能把“需要转换”误认为已经生成可提交页。

## 决定

1. 本机恶意文件扫描通过后，非 PDF 文件还必须经过按格式分类的有界结构检查；检查过程只读、不解压、不执行宏、不访问外链、不写入原案卷目录。
2. JPEG/PNG 校验真实解码格式、单帧和像素上限；HEIC 只校验容器签名，保留为隔离转换任务。
3. DOCX/XLSX 校验 ZIP/OOXML 必需结构，阻断宏、ActiveX、嵌入对象、外部关系、主动 XML 声明和越界关系路径。旧版 XLS 只在 OLE 签名正确时进入隔离转换。
4. ZIP 校验条目数、单项/总展开大小、压缩比、加密、符号链接、重复路径和路径穿越；本阶段不自动展开。
5. 文本校验大小、编码、二进制 NUL 和控制字符；EML 校验结构、分段上限和附件名。通过者仍是 `REVIEW_REQUIRED`，不登记虚构页数。
6. 每项结构结论以稳定原因码和检查哈希绑定到 Worker 结果。律师界面可按案件版本分页查看相对路径、状态和中文原因；不得返回绝对路径、租约、文件哈希或扫描器原始输出。

## 后果

后续转换 Worker 只接收结构上具备转换资格的材料，明显危险内容在进入 LibreOffice、图片渲染或邮件展开前已经阻断。代价是部分合法但复杂的文件会被保守地送入人工处理；这是当前阶段可接受的 fail-closed 取舍。

本决策不等于“非 PDF 已转换”。规范化 PDF、原件到规范化产物的谱系、稳定页映射、隔离运行时和转换结果复核仍是下一段实现内容。
