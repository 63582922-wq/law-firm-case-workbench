# ADR-0062：最高人民检察院公开法律镜像的精确域名登记

- 状态：已采纳
- 日期：2026-09-04
- 关联：ADR-0054、ADR-0055、ADR-0058、ADR-0061

## 背景

固定的被告应诉合成验收使用最高人民检察院官网公开的《中华人民共和国民法典》
页面，已按 ADR-0061 以固定哈希、字节数、媒体类型、租户和案件范围保存为不可变
私有对象。公共研究源目录已将 `www.spp.gov.cn` 登记为 `CN-CIVIL-CODE-680` 的
允许来源，但法律账本的正式来源 URL 校验表遗漏该精确主机。

这会在模型调用前阻断已认证来源快照登记；绕过账本校验、改用宽泛的 `*.gov.cn`，
或把已存储对象直接交给 Agent 都不符合可追溯和最小授权边界。

## 决策

1. 仅把 `www.spp.gov.cn` 加入正式法律来源 HTTPS 域名白名单；不加入泛 `gov.cn`、
   不加入通配域名，也不允许运行时任意扩展。
2. 该登记只解决 URL 的正式来源资格；TLS、无重定向、冻结内容哈希、字节数、媒体
   类型、私有对象加密认证、律师复核和后续规则批准门仍全部保留。
3. 增加回归测试，证明该主机能够通过 URL 白名单而仍会在未配置加密对象验证器时
   失败关闭。

## 后果

- 公共研究目录和正式法律账本对同一已登记主来源保持一致，受控验收可从已认证私有
  快照继续，而不必依赖公共网页短时可用性。
- 这不是对最高人民检察院以外网站的扩权，也不是对任何真实案件的自动法源批准。
