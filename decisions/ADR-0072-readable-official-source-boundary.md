# ADR-0072：来源绑定文书必须使用可安全读取的官方正文

- 状态：已采纳
- 日期：2026-09-04
- 关联：ADR-0057、ADR-0062、ADR-0069、ADR-0071

## 背景

V4 合成验收保留的最高人民检察院页面通过了原字节哈希、媒体类型和字符串标记检查，但运行时读取发现页面是动态空壳：条文标记存在于原始 HTML，安全 HTML 解析器却没有得到任何字面可见正文。文书 Worker 已正确拒绝把它当作 `VERIFIED_LEGAL_SOURCE` 的正文；旧的固定验收前置检查没有使用同一标准，形成了“可以启动模型、却不能生成来源绑定文书”的断点。

## 决策

1. 对任何进入来源绑定文书或固定 Agent 验收的 HTML、TXT、PDF，原字节哈希、媒体类型、URL 和关键词均不足够；必须能从已认证的原字节安全提取非空、受限长度的字面正文。
2. HTML 只采纳非活动、字面可见文本；脚本、样式、属性、嵌入页、远程资源和浏览器执行结果均不构成可引用正文。PDF 只允许其现有文字层，不在文书链中静默 OCR。
3. 固定验收的法源恢复、当前文书 Worker 和后续文书绑定共用该提取规则。任一环节失败即停止在法源治理阶段；不得调用模型、制造候选文书、填补法条、降级为“已核验”或自动替换来源。
4. 已封存的 V4 运行、模型响应、外发记录和旧来源快照保持不可变。它只能作为“历史封存响应可回放”的证据，不能因本 ADR 被改记成功，也不允许 V5 或重试。
5. 修复旧来源必须经过新的、明确授权的官方来源捕获、独立律师复核、正式快照/规则包版本更新和下游失效；不能把公开网页搜索结果或另一个机构页面直接塞入历史案件。

## 后果

- 空壳网页会更早、以明确原因被阻止，避免到文书生成阶段才暴露不可交付状态。
- 这缩小了可用来源集合，但保留了律师可审查、可定位、可追溯的最低证据标准。
- 本 ADR 不替代律师对法源版本、许可、条款适用或案件结论的审查。
