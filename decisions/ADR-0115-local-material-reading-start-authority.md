# ADR-0115：启动办案即授权本案内的本地读卷，不重复要求逐任务批准

状态：`Accepted`

日期：`2026-09-10`

## 问题

律师在案件首页点击“开始处理”后，统一 Agent 已经以该律师身份、当前案件快照和受管材料范围
创建了可审计运行。此前原生 PDF 与常用办公文档的本地读取仍要求第二个 `MATERIAL_SCOPE`
审批，导致系统在尚未读取任何材料时停住。这个重复按钮既不增加新的材料、网络、事实写入或
对外权限，也让律师误以为系统无法工作。

## 决定

对于当前案件已入卷材料的本地只读 PDF/Office 提取，`RUN_CREATED` 事件即是唯一需要的
律师启动授权。该任务使用 `NONE` 审批门、无网络、零外部调用、只读受管材料，并且不会写入
事实、交易、法律立场或对外成果。

视觉 OCR、外部模型、公开检索、事实/交易确认、法律意见、文书生成和提交仍按既有更严格的
审批与审阅边界执行。

## 后果

“开始办案”可以先完成本地读卷并形成待核对材料结果；律师只在真正需要外部处理或作出法律
决定时看到明确的审批动作。每轮本地读取仍由案件版本、来源快照、任务图、预算和审计事件
约束，不能读取其他案件或自行扩大材料范围。
